Tune 1.0.0-rc10、Tune 1.0 の 10 番目のリリース候補です。

## 新機能

- **マイ フィジカル コレクション**：新しいプラグインが、Discogs のコレクションをライブラリやストリーミングサービスと照合し、サーバーにキャッシュされたジャケットのグリッドで表示します。サイドバーの Tune Circle のすぐ下に専用の項目が追加されます。
- **マイテーマ**：インターフェースのすべての色をプロファイルごとに選べます。プラグインからテーマを提供することもでき、自分のテーマを Tune Circle の連絡先に送ると、相手はワンクリックで適用できます。
- **Crosstalk**：スピーカー間のクロストークを低減するプラグインが、設定画面とともに拡張機能カタログに加わりました。同じゾーンではクロスフィードをオフにし、その旨を表示します。
- **フォルダー**：フォルダーをすべてのサブフォルダーごと、順番どおりに再生またはキューに追加できます。ライブラリのディレクトリフィルターはサブフォルダーまでたどり、ライブラリ全体に戻ることもできます。
- **ラジオ**：マイラジオとディレクトリの「その他のフィルター」バーで条件検索ができます。ディレクトリに新しいジャンルが 4 つ加わりました。
- **ラジオ再生**：局のストリームが音質順に並びます。再生中画面に局のロゴと「マイラジオ」ボタンが表示されます。聴取国は 設定 › 一般 で設定します。
- **レーベル**：mozaiklabs.fr が共有するレコードレーベルのロゴを表示します。サーバーの状態画面で、アルバムジャケットとレーベルロゴの取得状況を確認できます。
- **音量**：スライダーが dB 目盛りになり、快適上限と安全上限が色で示されます。安全上限を超える快適上限は受け付けません。
- **Oxygen とメタデータ**：フィルター結果全体で 1 つのフィールドを一括編集できます。メタデータの自動補完から除外するフォルダーを指定できます。
- **Tune Circle**：ワールド表示で地球儀の一部を拡大できます。Tune Circle のプレイリストにはプレイリストのフィルターに専用のバッジが付きます。サービスのプレイリストをその詳細ページから共有できます。
- **デスクトップウィジェット**：ミニウィンドウが Web インターフェースのミニ表示を使うようになり、アーティスト、Qobuz、TIDAL の検索（サムネイル付き、キーボード操作対応）が加わりました。
- **AES67 出力**：AES67 互換の Dante および Ravenna オーディオネットワーク向けの実験的な出力を、設定 › 実験的機能 に追加しました（既定ではオフ）。

## 改善

- **このブラウザー**：次の曲を終了前に準備し、よりなめらかにつながります。サーバーの「このブラウザー」ゾーンは事前設定なしで再生できます。
- **再生の再開**：カードに再開するアルバム、プレイリスト、エピソードの名前が表示され、聴き終えたものは一覧から外れます。
- **履歴と人気曲**：開いたアルバムやプレイリストの曲が新しい順に並びます。アーティストの人気曲に、あなたがよく聴く曲をすべてのソースから加えます。
- **ライブラリ**：大規模なライブラリで DR と初出年のフィルターが大幅に速くなりました。曲リストの列幅を変更でき、画面ごとに記憶されます。音響解析は処理のペースを説明し、進行状況を表示します。
- **イコライザー**：周波数と Q を自由に入力でき、入力の完了時に確定します。読み込んだプリセットの削除には確認が求められます。ルーム補正と DAC キャリブレーションはイコライザープロファイル全体を適用します。
- **プレイリスト**：.m3u、.m3u8、.dpl の読み込みはプレイリストマネージャーにあり、実際の曲数を表示します。インポート、転送、比較は失敗の理由を示します。
- **ジャケット**：埋め込みジャケットをすべてのタグから、表面を優先して読み取ります。ファイルの再読み込みの後にオンライン検索を続けます。Qobuz プレイリストの横長の画像を欠けずに表示します。
- **メッセージ**：フランス語のまま残っていたエラーメッセージをインターフェースの言語に翻訳しました。接続を拒否する AirPlay 2 スピーカーはペアリング不足を知らせます。Qobuz に拒否されたアプリケーション ID を、パスワードの誤りとして表示しなくなりました。
- **ライセンス**：Premium が Mozaiklabs アカウントに由来することを画面に表示し、キーの入力を求めなくなりました。
- **ホーム**：「他のバージョン」がストリーミングサービスの応答待ちで止まらなくなりました。
- **ASIO**：DSD 対応を確認できない場合はその旨を伝え、出力でできることを説明します。

## 修正

- **再生**：PURE とイコライザーを切り替えても、停止中のゾーンが再開しなくなりました。「既定でリピート」のチェックを外すとゾーンのリピートが確実にオフになります。互換性のある曲どうしのつなぎ目は途切れません。
- **OpenHome**：一時停止と停止で、準備済みの次の曲をプレーヤーから外します。次の曲に移る間も終了位置を保持します。
- **ラジオ**：聴取国が不明でも、選んだストリームが 96 kbit/s のストリームに置き換えられなくなりました。コンソールから追加した局は詳細ページとのつながりを保ちます。単発の失敗でラジオのメタデータが停止しなくなりました。「最近再生した局」に正しい日付を表示します。ラジオのお気に入りから作成した Qobuz プレイリストがすぐに表示されます。
- **ライブラリとプロファイル**：お気に入りと評価のフィルターが現在のプロファイルに従います。「よく聴く曲」で 1 回の再生を複数回数えなくなりました。メタデータ補完が既存のジャンルを置き換えなくなりました。UPnP の曲が年とジャンルを保持します。すでに使われている MusicBrainz ID を二重に割り当てなくなりました。
- **コレクションとプレイリスト**：保存が拒否された場合に通知し、問題のあるフォルダーで一覧が空にならなくなりました。プレイリストのすべてのページを読み込みます。
- **プラグインとアカウント**：有効なネイティブプラグインをアンインストールすると、確実に無効のままになります。Mozaiklabs アカウントとの最初の連携は、メールアドレスがなくても唯一のプロファイルに紐づきます。
- **その他**：スキャン時のプレイリスト読み込みは、読み込まない理由を示します。設定の読み込みに失敗した場合、既定値に戻さず通知します。コンピューターのスリープをフリーズとして報告しなくなりました。旧インターフェースがサーバーの更新後に残らなくなりました。VU メーターのバーが 1280〜1800 px ではみ出さなくなりました。Windows の既定設定でも WASAPI モードが表示されます。音声を送信時に圧縮しなくなりました。
- **セキュリティ**：堅牢化のための修正。
