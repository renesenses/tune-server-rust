Tune 1.0.0-rc10，Tune 1.0 的第十个候选版本。

## 新功能

- **我的实体收藏**：新插件将你的 Discogs 收藏与音乐库及各流媒体服务进行比对，以缓存在服务器上的封面网格展示。侧边栏中紧随 Tune Circle 之后新增专属入口。
- **我的主题**：按配置文件自选界面的全部颜色。插件也可以提供主题，你还可以把自己的主题发送给 Tune Circle 联系人，对方一键即可应用。
- **Crosstalk**：用于减弱音箱间串扰的插件连同其设置界面加入扩展目录；在同一区域中，它会关闭交叉馈送（crossfeed）并加以提示。
- **文件夹**：可按顺序播放某个文件夹及其全部子文件夹，或将其加入队列；音乐库的目录筛选会深入子文件夹，并可返回整个音乐库。
- **电台**：“我的电台”和“电台目录”中的“更多筛选”栏支持按条件搜索；目录新增四种流派。
- **电台播放**：电台的各路音频流按音质排序；“正在播放”显示电台标志和“我的电台”按钮；收听国家在 设置 › 通用 中设置。
- **唱片公司**：显示由 mozaiklabs.fr 共享的唱片公司标志；服务器状态页可查看专辑封面和唱片公司标志的获取进度。
- **音量**：滑块以 dB 为刻度，舒适上限和安全上限以颜色标示，高于安全上限的舒适上限将被拒绝。
- **Oxygen 与元数据**：可对整个筛选结果统一修改某个字段；可将文件夹排除在元数据自动补全之外。
- **Tune Circle**：在“世界”视图中可放大地球上的某个区域；Tune Circle 歌单在歌单筛选中有专属标记；流媒体服务的歌单可在其详情页分享。
- **桌面小组件**：迷你窗口改用网页界面的迷你视图，并新增艺人、Qobuz 和 TIDAL 搜索，支持缩略图和键盘操作。
- **AES67 输出**：面向兼容 AES67 的 Dante 和 Ravenna 音频网络的实验性输出，默认关闭，位于 设置 › 实验功能。

## 改进

- **此浏览器**：在曲目结束前预先准备下一首，衔接更顺畅；服务器的“此浏览器”区域无需预先设置即可播放。
- **继续收听**：卡片会显示所继续的专辑、歌单或单集名称，听完的内容会从列表中移除。
- **历史记录与热门曲目**：打开的专辑或歌单中的曲目按从新到旧排列；艺人的热门曲目会加入你在所有来源中最常听的曲目。
- **音乐库**：在大型音乐库中，按 DR 和原始年份筛选明显更快；曲目列表的列宽可调整，每个页面都会记住列宽；声学分析会说明处理节奏并显示进度。
- **均衡器**：频率和 Q 值可自由输入，在输入结束时生效；删除导入的预设需要确认；房间校正和 DAC 校准会应用完整的均衡器配置。
- **歌单**：.m3u、.m3u8 和 .dpl 导入位于歌单管理器中，并报告实际曲目数；导入、迁移和比较会说明失败原因。
- **封面**：从所有标签中读取内嵌封面，优先使用正面；重新读取文件后继续在线搜索；Qobuz 歌单的长方形图片完整显示。
- **提示信息**：最后一批仍为法语的错误信息已翻译为界面语言；拒绝连接的 AirPlay 2 音箱会提示缺少配对；被 Qobuz 拒绝的应用 ID 不再被显示为密码错误。
- **许可证**：页面会说明 Premium 来自你的 Mozaiklabs 账户，无需输入密钥。
- **首页**：“其他版本”不再因等待流媒体服务而卡住。
- **ASIO**：无法确认 DSD 支持时，Tune 会如实提示并说明该输出的能力。

## 修复

- **播放**：在 PURE 与均衡器之间切换不再重新启动已停止的区域；取消勾选“默认循环播放”会真正关闭该区域的循环；兼容曲目之间的过渡保持连续。
- **OpenHome**：暂停和停止会从播放器中移除已准备的下一首，切换到下一首期间保留结束位置。
- **电台**：收听国家未知时，所选音频流不再被替换为 96 kbit/s 的流；从控制台添加的电台保留与其详情页的关联；单次失败不再暂停电台元数据；“最近播放”显示正确日期；从电台收藏创建的 Qobuz 歌单会立即出现。
- **音乐库与配置文件**：收藏和评分筛选跟随当前配置文件；“最常播放”不再将一次收听重复计数；元数据补全不再替换已有流派；UPnP 曲目保留年份和流派；已被使用的 MusicBrainz 标识不再被重复分配。
- **收藏集与歌单**：保存被拒绝时会提示，有问题的文件夹不再清空列表，歌单的所有页面都会被读取。
- **插件与账户**：卸载已启用的原生插件后会持续保持停用；首次关联 Mozaiklabs 账户时，即使没有电子邮件地址也会关联到唯一的配置文件。
- **其他**：扫描时的歌单导入会说明未导入的原因；读取设置失败时会提示，而不是退回默认值；电脑休眠不再被报告为卡死；服务器更新后旧界面不再残留；VU 表栏在 1280 至 1800 px 之间不再溢出；使用 Windows 默认设置时 WASAPI 模式仍然可见；音频在发送时不再被压缩。
- **安全**：加固修复。
