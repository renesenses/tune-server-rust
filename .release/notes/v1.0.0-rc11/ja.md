Tune 1.0.0-rc11、Tune 1.0 の 11 番目のリリース候補です。

## 新機能

- **ルーム補正**: 既定では無効のプラグインが、マイクで部屋を測定(スイープ、インパルス応答、RT60)するか、マイクなしで低音のモードをシミュレートし、ターゲットと、カットのみを行う自動イコライザーをゾーンごとのプロファイルとともに提案します。Premium でない場合、インパルス応答によるコンボリューションはフェードアウトします。
- **ペアレンタルコントロール**: 設定 › プロフィールでプロフィールごとのルール、露骨なコンテンツの非表示、時間帯、再生時間の上限を設定できます。
- **アップサンプリング**: Premium の高品質アップサンプリングプラグインをローカル出力に接続でき、ゾーンごとに設定できます。
- **高度なクエリ**: スマートコレクションを定義するのと同じ式で、ライブラリを検索できます。
- **アルバムごとに 1 ページ**: アルバムのバージョンがまとめられ、ページ内で選べます。DSD 品質とマルチチャンネルの新しいフィルターとチャンネル数も表示されます。
- **メモと統計**: Markdown で書く個人メモと、内訳別のライブラリ統計。
- **カタログとスペクトログラム**: 現在のフィルターを反映して、ライブラリを印刷可能な HTML カタログとして書き出せます。トラックのメニューからスペクトログラムを表示でき、ボタンでトラック間の DR 解析を停止できます。
- **世界地図**: ライブラリに国別マップと国フィルターを追加。地球儀には国境、海岸線、主要な河川が描かれ、ポインターを重ねると国名が表示されます。
- **ポッドキャスト**: RSS フィードのアドレスからポッドキャストを追加できます。
- **TIDAL ミックス**: ストリーミング › TIDAL の「あなたのミックス」の行に、アカウントのパーソナルミックスが表示され、再生できます。
- **イコライザーの読み込み**: イコライザーのファイル(AutoEq、Equalizer APO、OPRA)を、適用前にバンドのプレビューを確認しながら読み込めます。
- **アーティスト紹介**: Tune のアーティストやアルバム、情報源へのリンク。紹介文とアルバムのメモは Qobuz から必要に応じて補完され、既存の内容を上書きせず、元に戻せます。
- **プレイリスト**: 利用できないサービスのトラックをその位置で置き換え、プレイリストを修復できます。
- **Tune Circle**: メッセージからサークル全体に書き込めます。一般サークルとスレッドの同意はリレーを経由します。
- **フィジカルコレクション**: 各ディスクのジャケット、ストリーミングサービスでの検索、フォルダー・ジャンル・スタイルによる閲覧。

## 改善

- **ラジオ**: 「その他のフィルター」でストリームの最低品質を指定でき、「マイラジオ」と「最近聴いた」が分かれ、既定のストリームは視聴国で常に再生できます。
- **Tune tested**: エラーなしで 1 時間聴くと、専用ボタンからデバイスの追加を提案します。すでにカタログにあるデバイスは世帯として追加されます。
- **ライブラリ**: 「サービスのお気に入りまで広げたライブラリ」設定(既定で有効)、単語の先頭での検索の高速化、グリッド検索はすべての語を要求、年のタイムラインに期間(開始 / 終了)、トラックのスクロールが滑らかに。
- **トラック一覧**: 列の順序を変更でき、画面ごとに記憶されます。プレイリスト画面にジャケット、サムネイルサイズ、コンパクトなヘッダーを追加。プレイリストマネージャーにソースのバッジ。
- **ホームと再開**: 再生概要のパネルを選べます。「聴き続ける」は種類ごとにサブタイトルを表示し、ポッドキャストをタイトル、ジャケット、位置とともに、重複なしで再開します。
- **履歴**: 30 秒または曲の半分を聴いて初めて 1 回と数えます。停止後の「再生」は現在のアルバムまたはプレイリストを保持し、ポッドキャストのエピソードとラジオには局名が付きます。
- **再生統計**: 読み込んだ再生(Roon、Plex、m3u)も最も聴いた項目に数えられ、スマートリストと履歴はライブラリと同じ数え方になり、Qobuz の再生は同名のローカルアルバムに数えられなくなりました。
- **Crosstalk とイコライザー**: 設定画面に分離 / 着色カーブとスピーカー応答を追加、分離の目標は 1 dB から。パラメトリックグラフは既定で固定(編集 / 完了)、チャンネルごとに色分け。
- **拡張機能**: 管理者向けの「プラグインの状態」パネル。カタログの項目とローカルのプラグインは 1 つの拡張機能になりました。
- **通知**: エラーは残り、ポインターを重ねると一時停止し、まとめて表示されます。固定のまま残っていたエラーメッセージも翻訳され、例外の生テキストは「詳細」に折りたたまれます。
- **バックグラウンド解析**: 進行状況を表示し、スキャン後は低い優先度と慎重な既定値で動作します。エンリッチメントは中断した位置から再開し、503 の後に再試行します。レーベルロゴの「パスを実行」は一時停止中でも動作します。
- **サポートとリモートアクセス**: 不具合報告にログを添付。リンク、QR コード、コピーボタンが設定 › リモートアクセスに戻りました。
- **再生**: トランスコードの理由が明示され、該当がなければ FLAC はそのまま配信されます。「次へ」と「前へ」はサービスが拒否したトラックをスキップします。

## 修正

- **AirPlay 2**: 「Pair」ボタンは AirPlay 2 コンポーネントでペアリングするか、原因を示します。PIN の待機は再生を妨げず、そのウィンドウを閉じると待機をキャンセルします。一時停止後にセッションを開き直し、位置が進み、一時停止がループしなくなりました。コンポーネントは 64 ビット Raspberry Pi 向けにも用意されています。
- **DLNA と OpenHome**: DSD トラックのギャップレス再生、「次へ」の高速化、デバイス側で行った一時停止の尊重、マシン自身の出力が二重に表示されない、OpenHome の音量を待たずに反映、Kazoo が読み込んだリストの保持、TIDAL CD の Play の高速化。
- **音量**: 新しいローカル出力が最大レベルで始まらなくなり、ミュートで読み直された音量が通らなくなり、スライダーの各位置が異なるレベルになり、WASAPI と ASIO の音量がすぐに聞こえ、Tune は安全上限以下でデバイスに追従します。
- **Windows**: ショートカットがコンソールウィンドウなしで開き、出力が運べない DoP は PCM で送られ、ネットワーク検出がファイアウォールを通り、読み取れない温度で解析が抑制されなくなり、更新は終了時に切り替えスクリプトを起動します。
- **更新とライセンス**: Unix では、新しいバイナリと Web インターフェースを検証してから置き換え、失敗は明示されます。ライセンスを外すと、サイト側でもマシンが解放されます。
- **ライブラリ**: UPnP サーバーの写真や動画が取り込まれなくなり、FLAC + CUE のボックスセットは 1 つのアルバムになり、DSD 版と CD 版は別々のアルバムのままで、手作りのコンピレーションは分割されず、削除したプレイリストはスキャンで再作成されず、アーティストタグのない再読み込みでアルバムが「Unknown Artist」に移らず、フォルダーを追加するとそのフォルダーだけをスキャンします。
- **ジャケットと解析**: 最後の手段としてフォルダー内で最大の画像を使用、偽ハイレゾの解析は曲の全長を対象、MP3 のギャップレス再生、整合性チェックは無傷の FLAC を切り詰めと判定しなくなりました。
- **ストリーミングサービス**: Spotify の検索が結果を返し、拒否が無言ではなくなり、お気に入りが 50 曲を超えて表示されます。TIDAL › お気に入りで Tune が固まらず、お気に入りのない Qobuz アカウントは空のリストをすぐ返し、変換されたトラックが Safari で再生を始めます。
- **ネットワークとストレージ**: Tune より後にネットワークが現れても検出が再開し、失敗した SMB マウントは Docker でも理由を示し、PostgreSQL でバックアップが完了し、CD の取り込みは満杯または書き込み不可の保存先を拒否し、Squeezebox のポートは同じマシンの Lyrion サーバーに譲られます。
- **画面**: コンサート画面がライセンスなしで開き、「すべてグループ解除」が再び表示され、再生中画面がアルバムの変更に追従し、期限切れのストリーミングセッションは「再接続」タブを保ち、新規アラームが見えたままになります。
- **セキュリティ**: 堅牢化のための修正。
