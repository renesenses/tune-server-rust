Tune 1.0.0-rc11, Tune 1.0의 열한 번째 릴리스 후보입니다.

## 새로운 기능

- **룸 보정**: 기본적으로 꺼져 있는 플러그인이 마이크로 공간을 측정(스윕, 임펄스 응답, RT60)하거나 마이크 없이 저음 모드를 시뮬레이션한 다음, 목표와 감쇠만 하는 자동 이퀄라이저를 존별 프로필과 함께 제안합니다. Premium이 없으면 임펄스 응답 컨볼루션은 페이드 아웃됩니다.
- **자녀 보호**: 설정 › 프로필에서 프로필별 규칙, 선정적인 콘텐츠 숨기기, 시간대, 청취 시간 한도를 설정합니다.
- **업샘플링**: Premium 고품질 업샘플링 플러그인이 로컬 출력에 연결되며, 존별 설정을 제공합니다.
- **고급 쿼리**: 스마트 컬렉션을 정의하는 것과 같은 식으로 라이브러리를 검색합니다.
- **앨범당 한 페이지**: 앨범의 버전이 묶여 페이지에서 선택할 수 있고, DSD 품질과 멀티채널 필터, 채널 수가 새로 표시됩니다.
- **메모와 통계**: Markdown 개인 메모와 분포별 라이브러리 통계.
- **카탈로그와 스펙트로그램**: 현재 필터를 적용해 라이브러리를 인쇄 가능한 HTML 카탈로그로 내보내고, 트랙 메뉴에서 스펙트로그램을 표시하며, 버튼으로 트랙 사이의 DR 분석을 중지할 수 있습니다.
- **세계 지도**: 라이브러리에 국가 지도와 국가 필터가 생겼고, 지구본에는 국경, 해안선, 주요 강이 그려지며 마우스를 올리면 국가 이름이 표시됩니다.
- **팟캐스트**: RSS 피드 주소로 팟캐스트를 추가합니다.
- **TIDAL 믹스**: 스트리밍 › TIDAL의 「내 믹스」 줄에서 계정의 개인 믹스를 보고 재생합니다.
- **이퀄라이저 가져오기**: 이퀄라이저 파일(AutoEq, Equalizer APO, OPRA)을 적용하기 전에 밴드 미리보기와 함께 가져옵니다.
- **아티스트 소개**: Tune의 아티스트와 앨범, 원본 출처로 가는 링크. 소개와 앨범 노트는 필요할 때 Qobuz에서 보완되며, 기존 내용을 덮어쓰지 않고 되돌릴 수 있습니다.
- **플레이리스트**: 사용할 수 없는 서비스 트랙을 제자리에서 교체하고 플레이리스트를 복구합니다.
- **Tune Circle**: 메시지에서 서클 전체에 글을 쓸 수 있습니다. 일반 서클과 스레드 동의는 릴레이를 거칩니다.
- **실물 컬렉션**: 디스크별 커버, 스트리밍 서비스 검색, 폴더·장르·스타일별 탐색.

## 개선

- **라디오**: 「추가 필터」에서 최소 스트림 품질로 필터링하고, 「내 라디오」와 「최근 들은 곡」이 분리되며, 기본 스트림은 청취 국가에서 항상 재생할 수 있습니다.
- **Tune tested**: 오류 없이 1시간 들으면 전용 버튼으로 기기 추가를 제안합니다. 이미 카탈로그에 있는 기기는 가구로 추가됩니다.
- **라이브러리**: 「서비스 즐겨찾기까지 확장한 라이브러리」 설정(기본 켜짐), 단어 앞부분 검색 속도 향상, 그리드 검색은 모든 단어를 요구, 연도 타임라인에 시작 / 종료 기간, 트랙 스크롤이 더 부드러워짐.
- **트랙 목록**: 열 순서를 바꿀 수 있고 화면마다 기억됩니다. 플레이리스트 화면에 커버, 썸네일 크기, 간결한 헤더가 추가되었고 플레이리스트 관리자에 출처 배지가 생겼습니다.
- **홈과 이어 듣기**: 청취 개요의 패널을 선택할 수 있습니다. 「이어 듣기」는 종류별 부제목을 표시하고, 팟캐스트를 제목, 커버, 위치와 함께 중복 없이 이어 재생합니다.
- **기록**: 30초 또는 곡의 절반을 들어야 청취로 인정됩니다. 정지 후 「재생」은 현재 앨범이나 플레이리스트를 유지하고, 팟캐스트 에피소드와 라디오에는 방송국 이름이 붙습니다.
- **청취 통계**: 가져온 청취(Roon, Plex, m3u)도 가장 많이 들은 항목에 포함되고, 스마트 목록과 기록은 라이브러리와 같은 방식으로 집계되며, Qobuz 청취는 같은 이름의 로컬 앨범에 더 이상 집계되지 않습니다.
- **Crosstalk와 이퀄라이저**: 설정 화면에 분리 / 색채 곡선과 스피커 응답을 추가했고 분리 목표는 1 dB부터입니다. 파라메트릭 그래프는 기본적으로 고정(편집 / 완료)되며 채널마다 색이 다릅니다.
- **확장 기능**: 관리자용 「플러그인 상태」 패널. 카탈로그 항목과 로컬 플러그인은 이제 하나의 확장 기능입니다.
- **알림**: 오류가 유지되고, 마우스를 올리면 일시 정지되며, 그룹으로 묶입니다. 하드코딩되어 있던 마지막 오류 메시지도 번역되었고, 예외 원문은 「세부 정보」에 접혀 있습니다.
- **백그라운드 분석**: 진행 상황을 표시하고, 스캔 뒤에는 낮은 우선순위와 신중한 기본값으로 동작합니다. 보강 작업은 중단한 곳에서 이어지고 503 뒤에 재시도하며, 레이블 로고의 「패스 실행」은 일시 중지 중에도 동작합니다.
- **지원과 원격 접속**: 버그 보고서에 로그를 첨부합니다. 링크, QR 코드, 복사 버튼이 설정 › 원격 접속에 돌아왔습니다.
- **재생**: 트랜스코딩 사유가 표시되고 해당 사항이 없으면 FLAC은 그대로 제공됩니다. 다음 / 이전은 서비스가 거부한 트랙을 건너뜁니다.

## 수정

- **AirPlay 2**: 「Pair」 버튼이 AirPlay 2 구성 요소로 페어링하거나 원인을 알려 줍니다. PIN 대기가 재생을 막지 않고 창을 닫으면 대기가 취소되며, 일시 정지 후 세션이 다시 열리고, 위치가 진행되며 일시 정지가 반복되지 않습니다. 구성 요소는 64비트 Raspberry Pi용으로도 제공됩니다.
- **DLNA와 OpenHome**: DSD 트랙의 끊김 없는 재생, 더 빠른 「다음」, 기기에서 한 일시 정지 존중, 기기 자체 출력이 중복 표시되지 않음, 기다리지 않는 OpenHome 볼륨, Kazoo가 불러온 목록 유지, TIDAL CD의 더 빠른 Play.
- **볼륨**: 새 로컬 출력이 최대 레벨로 시작하지 않고, 음소거 중 다시 읽은 볼륨이 통과하지 않으며, 슬라이더의 각 위치가 서로 다른 레벨을 내고, WASAPI와 ASIO 볼륨이 즉시 들리며, Tune은 안전 상한 아래에서 기기를 따릅니다.
- **Windows**: 바로 가기가 콘솔 창 없이 열리고, 출력이 전달할 수 없는 DoP는 PCM으로 나가며, 네트워크 검색이 방화벽을 통과하고, 읽을 수 없는 온도가 분석을 더 이상 제한하지 않으며, 업데이트가 종료 시점에 전환 스크립트를 실행합니다.
- **업데이트와 라이선스**: Unix에서는 새 바이너리와 웹 인터페이스를 검증한 뒤 기존 것을 교체하며 실패는 명확히 표시됩니다. 라이선스를 제거하면 사이트에서도 기기가 해제됩니다.
- **라이브러리**: UPnP 서버의 사진과 동영상이 더 이상 들어오지 않고, FLAC + CUE 박스 세트는 하나의 앨범이 되며, DSD 에디션과 CD 에디션은 두 앨범으로 유지되고, 직접 만든 컴필레이션이 쪼개지지 않으며, 삭제한 플레이리스트가 스캔 때 다시 만들어지지 않고, 아티스트 태그가 없는 재읽기가 앨범을 「Unknown Artist」로 옮기지 않으며, 폴더를 추가하면 그 폴더만 스캔합니다.
- **커버와 분석**: 최후의 수단으로 폴더에서 가장 큰 이미지 사용, 곡 전체 길이에 걸친 가짜 Hi-Res 분석, 끊김 없는 MP3, 무결성 검사가 멀쩡한 FLAC을 잘렸다고 판정하지 않습니다.
- **스트리밍 서비스**: Spotify 검색이 결과를 반환하고, 거부가 더 이상 조용하지 않으며, 즐겨찾기가 50곡을 넘습니다. TIDAL › 즐겨찾기에서 Tune이 멈추지 않고, 즐겨찾기가 없는 Qobuz 계정은 빈 목록을 빠르게 반환하며, 변환된 트랙이 Safari에서 시작됩니다.
- **네트워크와 저장소**: Tune보다 늦게 네트워크가 나타나도 검색이 재개되고, 실패한 SMB 마운트는 Docker에서도 이유를 알려 주며, PostgreSQL에서 백업이 완료되고, CD 추출은 가득 찼거나 쓸 수 없는 대상을 거부하며, Squeezebox 포트는 같은 컴퓨터의 Lyrion 서버에 양보됩니다.
- **화면**: 콘서트 화면이 라이선스 없이 열리고, 「모두 그룹 해제」가 다시 나타나며, 지금 재생 중 화면이 앨범 변경을 따라가고, 만료된 스트리밍 세션은 「다시 연결」 탭을 유지하며, 새 알람이 계속 보입니다.
- **보안**: 보안 강화 수정.
