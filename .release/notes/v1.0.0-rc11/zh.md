Tune 1.0.0-rc11，Tune 1.0 的第十一个候选版本。

## 新功能

- **房间校正**：一个默认关闭的插件用麦克风测量房间(扫频、脉冲响应、RT60),或在没有麦克风时模拟其低频模式,然后给出目标曲线和只做衰减的自动均衡器,每个分区一个配置;没有 Premium 时,脉冲响应卷积会渐隐关闭。
- **家长控制**：在设置 › 配置文件中按配置文件设置规则,隐藏不当内容,设定时间段和收听时长上限。
- **升采样**：Premium 高品质升采样插件接入本地输出,并可按分区设置。
- **高级查询**：用一个表达式查询曲库,与定义智能合集的表达式相同。
- **每张专辑一页**：专辑的各个版本被归并,可在专辑页中选择;新增 DSD 音质和多声道筛选以及声道数。
- **笔记与统计**：支持 Markdown 的个人笔记,以及按分布统计的曲库数据。
- **目录与频谱图**：按当前筛选条件把曲库导出为可打印的 HTML 目录;从曲目菜单显示频谱图;一个按钮可在两首曲目之间停止 DR 分析。
- **世界地图**：曲库中新增国家地图和按国家筛选;地球仪绘出国界、海岸线和主要河流,悬停时显示国家名称。
- **播客**：通过 RSS 订阅源地址添加播客。
- **TIDAL 合辑**：Streaming › TIDAL 中的“你的合辑”一行显示并播放账户的个人合辑。
- **均衡器导入**：导入均衡器文件(AutoEq、Equalizer APO、OPRA),应用前可预览各频段。
- **艺人简介**：链接到 Tune 中的艺人和专辑以及来源;简介和专辑说明可按需从 Qobuz 补全,不覆盖任何内容,并可撤销。
- **播放列表**：就地替换不可用的服务曲目,并修复播放列表。
- **Tune Circle**：在消息中给整个圈子写信;通用圈子和会话的同意状态经由中继传递。
- **实体收藏**：每张碟的封面、在流媒体服务中搜索、按文件夹、流派和风格浏览。

## 改进

- **电台**：在“更多筛选”中按最低码流质量筛选,“我的电台”与“最近收听”分开,默认码流在收听国家始终可播放。
- **Tune tested**：无错误收听一小时后,Tune 会通过专用按钮建议添加设备;已在目录中的设备会增加一个家庭。
- **曲库**：“曲库扩展到服务收藏”设置(默认开启),按词首搜索更快,网格搜索要求包含所有词,年份时间线增加起止时间段,曲目滚动更流畅。
- **曲目列表**：可更改列顺序,每个界面会记住;播放列表界面增加封面、缩略图大小和紧凑标题;播放列表管理器中增加来源徽标。
- **主页与继续收听**：可选择收听概览的面板;“继续收听”按类型显示副标题,播客连同标题、封面和位置继续播放,且不再重复。
- **历史**：收听满 30 秒或曲目一半才计为一次收听;停止后点“播放”会保留当前专辑或播放列表;播客节目和电台带有电台名称。
- **收听统计**：导入的收听记录(Roon、Plex、m3u)计入最常听;智能列表和历史与曲库的计法一致;Qobuz 的收听不再计入同名的本地专辑。
- **Crosstalk 与均衡器**：设置界面新增分离 / 染色曲线和音箱响应,目标分离度低至 1 dB;参量图默认锁定(编辑 / 完成),每个声道一种颜色。
- **扩展**：为管理员提供“插件状态”面板;目录条目与其本地插件现在合为一个扩展。
- **通知**：错误会保留,悬停时暂停并合并显示;最后一批写死的错误信息已翻译;异常的原始文本折叠在“详情”中。
- **后台分析**：显示进度,扫描后优先级较低且默认值更谨慎;内容丰富化从中断处继续,遇到 503 后重试;厂牌标志的“运行一遍”在暂停时也有效。
- **支持与远程访问**：错误报告附带日志;链接、二维码和复制按钮回到设置 › 远程访问。
- **播放**：会说明转码原因,无需处理时 FLAC 原样提供;“下一首”和“上一首”会跳过服务拒绝的曲目。

## 修复

- **AirPlay 2**：“Pair”按钮通过 AirPlay 2 组件配对,或说明原因;等待 PIN 不再阻塞播放,关闭其窗口即取消;暂停后会话会重新打开;位置继续前进,暂停不再循环;该组件也提供给 64 位 Raspberry Pi。
- **DLNA 和 OpenHome**：DSD 曲目无缝衔接,“下一首”更快,在设备上执行的暂停会被遵循,本机自己的输出不再重复出现,OpenHome 音量无需等待,Kazoo 载入的列表得以保留,TIDAL CD 的播放更快。
- **音量**：新的本地输出不再以满量程启动;静音不再放过重新读取的音量;滑块每个位置对应不同电平;WASAPI 和 ASIO 音量立即生效;Tune 在安全上限以下跟随设备。
- **Windows**：快捷方式打开时没有控制台窗口;输出无法承载的 DoP 改以 PCM 发送;网络发现可通过防火墙;读取不到的温度不再限制分析;更新在退出时启动切换脚本。
- **更新与许可**：在 Unix 上,新的二进制文件和网页界面验证通过后才替换旧版本,失败会明确提示;移除许可也会在网站上释放该机器。
- **曲库**：UPnP 服务器的照片和视频不再进入曲库;FLAC + CUE 套装合为一张专辑;DSD 版和 CD 版仍是两张专辑;手工合辑不再被拆散;已删除的播放列表不再在扫描时重建;没有艺人标签的重新读取不再把专辑归入“Unknown Artist”;添加文件夹只扫描该文件夹。
- **封面与分析**：作为最后手段使用文件夹中最大的图片;伪 Hi-Res 分析覆盖整首曲目;MP3 无缝播放;完整性检查不再把完好的 FLAC 判为被截断。
- **流媒体服务**：Spotify 搜索能返回结果,被拒绝时不再沉默,收藏可超过 50 首;TIDAL › 收藏不再卡死 Tune;没有收藏的 Qobuz 账户很快返回空列表;转换后的曲目可在 Safari 中开始播放。
- **网络与存储**：网络晚于 Tune 出现时,发现功能会恢复;失败的 SMB 挂载会说明原因,Docker 下同样如此;PostgreSQL 下备份可以完成;CD 提取会拒绝已满或不可写的目标位置;Tune 把 Squeezebox 端口让给同一台机器上的 Lyrion 服务器。
- **界面**：音乐会界面无需许可即可打开;“全部取消分组”重新出现;正在播放界面跟随专辑变化;过期的流媒体会话保留“重新连接”标签;“新建闹钟”保持可见。
- **Raspberry Pi 5**：Active Cooler 风扇恢复转动（新的 Tune OS 镜像）。
- **安全**：加固修复。
