Tune 1.0.0-rc12、Tune 1.0 の 12 番目のリリース候補です。いくつかの画面が、Tune コミュニティのデザイナー Levente による新しいデザインになりました。

## 新機能

- **新しいインターフェース**: Tune Circle を再設計（発見、メッセージ、共有プレイリスト、マイサークル）。アルバムページに説明、クレジット、詳細、カタログ番号を表示する「バージョン」タブ。アーティストページに大きなポートレート、数値、タブ。設定は読みやすい 1 列に。サーバーの状態と再生ダッシュボードは期間を選べます。
- **ホーム**: 新しいウィジェット「再生概要（新しいレイアウト）」をホーム › 編集から追加でき、ゾーンパネルを備えます。タイルが大きくなり、年とジャンルを表示します。
- **ライブラリ**: フィルターボタンで好きなフィルターをピン留め。クラシック音楽向けに指揮者、アンサンブル / オーケストラ、作品。チャンネル数とステレオフィルター。アーティストの国による地図とフィルター。音楽フォルダーの「パスを置き換え」。偽ハイレゾの検出（既定では無効）。
- **トラックの技術情報**: スペクトログラムとチャンネルごとの波形。ライブラリ内の Qobuz と TIDAL のトラックにも対応します。
- **キュー終了後のラジオ**: キューが終わると、Tune は似たトラックを「ラジオ」の印を付けて再生し続けます。ゾーンごとに設定できます。
- **スリープタイマー**: 選んだ時刻に音楽が止まります。Tune OS ではマシンの電源も切れます。
- **プレイリスト**: 各行に再生回数と最後の再生日時。「削除」の×印と「このプレイリストから削除」。自分の Qobuz プレイリストからトラックを削除できます。
- **ラジオ**: ロスレス、高品質、ハイレゾのフィルターを 1 行に。ディレクトリの局を自分用に編集でき、ラジオをプレイリストに追加できます。
- **再生**: Linux のローカル出力（ALSA）でネイティブ DSD。ゾーンごとの固定 PCM レート。排他モードをゾーンごとに設定。削除したゾーンを復元可能。CD の本物の AccurateRip 検証。
- **DLNA**: 2 曲のつなぎがうまくいかないレンダラー向けに、トラック間の連続ストリーム（既定では無効）。グループのマスター音量をどのメンバーからでも調整できます。
- **ストリーミング**: TIDAL カタログの国を選択。Qobuz の新着は Qobuz プレーヤーと同じに。Spotify に接続アシスタント、Spotify Connect は選んだゾーンで再生します。
- **信号経路**: 処理をクリックするとその設定が開き、グループ再生では各出力が表示されます。
- **設定とインターフェース**: 設定項目の検索、文字サイズ、波形のプログレスバー、すべての画面で共通の検索欄、アシスタントでの音声入力。

## 改善

- **速度**: 大きなライブラリでスマートコレクションとアルファベットジャンプが大幅に高速化。大きなリストでサーバーが遅くならなくなりました。
- **メモリ**: 長時間の再生中に解放したメモリを Tune が返却し、トランスコードのメモリには上限が設けられました。
- **再生開始**: YouTube の再生開始が速くなり、ローカル出力や OAAT 出力では TIDAL がトラック全体のダウンロードを待たなくなりました。
- **統計**: すべての画面でトラックとアルバムの合計が一致し、コーデックごとに 1 項目、ランキング全体を検索できます。
- **Tune Circle**: メッセージで絵文字を使えます。連絡先での再生が閉じているときは、Tune が自分のソースから同じトラックを探します。
- **モバイルアプリ**: CarPlay は電話で直接再生し、コレクションとラジオタブを備えます。Android には TIDAL カタログ、ラジオとポッドキャストの履歴、「お気に入りのラジオ」ウィジェットが加わりました。
- **Windows**: ファイアウォールが Tune を遮断しているとバナーで知らせ、ローカルゾーンに WASAPI または ASIO のバッジを表示します。
- **Docker**: SMB 共有アシスタントがイメージ内で動作し、CD ドライブをコンテナで使えます。
- **翻訳**: 15 言語すべてで複数形が正しくなりました。
- **依存関係**を更新（同梱の SQLite 3.54 を含む）。

## 修正

- **Web インターフェース**: インターフェースの更新後に黒い画面にならなくなりました。
- **ミュート**: ミュート中のゾーンは新しいトラックが始まっても無音のままで、アラームや音量制限でミュートが解除されなくなりました。
- **再生**: 破損したファイルでゾーンが固まらず、Tune は次へ進みます。聴き終えたポッドキャストのエピソードが最後の位置で開き直されなくなりました。
- **AirPlay 2**: 一時停止後は止まった位置から再開し、最大音量ではなく必ずゾーンの音量で始まります。
- **DLNA とグループ**: エラー 701 の後に再生が再開し、次のトラックが事前に準備され、応答しないデバイスが他のゾーンを妨げなくなり、Sonos はモデル名で表示されます。
- **HQPlayer、Devialet、Diretta**: 位置と状態を追跡し、自動で再接続します。Devialet アンプが再び応答し、Diretta に見かけだけの音量スライダーが表示されなくなりました。
- **OAAT**: ネイティブ DSD が正しく表示され、ビットパーフェクトに。DSD1024 を認識し、対応が限られたレシーバーでは PCM にフォールバックします。
- **ラジオ**: 局の重複がなくなり、お住まいの国で拒否されたラジオは次のストリームに切り替わります。
- **Spotify、Qobuz、TIDAL**: Spotify のプレイリストとお気に入りが新しい API に対応。Qobuz の拒否が認証情報の誤りとして表示されなくなり、TIDAL の先読みで再生が遅れなくなりました。
- **ライブラリ**: 再生はトラックごとに数えられ、ハイフンで偽のアーティストが作られなくなり、ボックスセットのディスクがより正しく認識され、年のないトラックはアルバムの年を引き継ぎます。
- **Windows**: DAC がないときに音が PC のスピーカーに流れなくなり、フォルダーの監視がネットワーク共有も対象にします。
- **PostgreSQL 18**: UPnP のお気に入りが再び機能します。

## セキュリティ

- ネットワーク上の別のマシンから Tune を管理するには、ログインが必要になりました（Tune OS: 新しいイメージから）。
- Webhook は Tune マシン自体を宛先にできなくなりました。
- Home Assistant と Hue の設定には、管理者権限または Tune マシン自体からの操作が必要です。Tune と同じマシンにインストールされた Home Assistant はサポートされなくなりました。

## 既知の問題

- **ローカル出力での DoP による DSD**: 減衰した PCM の後に、音量を無視してフルスケールで再生されることがあります。PCM のトラックから DoP の DSD トラックに移るときは、アンプの音量を低くしておいてください（次のバージョン）。
- **整合性監査**: 多くの FLAC が誤って破損と報告されることがあります。この判定だけでファイルを削除しないでください。
- **別のサーバーから制御される Windows ASIO**: 一時停止してから再生すると音が出ません。次のトラックに進んでください。
- **アップデート後**: インターフェースが変わらない場合は、強制的に再読み込みしてください（Cmd+Shift+R または Ctrl+Shift+R）。2 つのインデックスを作成するため、初回の起動には時間がかかります。
