Tune 1.0.0-rc12，Tune 1.0 的第十二个候选版本。多个界面采用了由 Tune 社区设计师 Levente 绘制的新设计。

## 新功能

- **全新界面**：重新设计的 Tune Circle（发现、消息、共享播放列表、我的圈子）；专辑页包含简介、制作人员、详细信息，以及显示目录编号的“版本”标签页；艺人页带有大幅肖像、数据和标签页；设置采用更易读的单栏布局；服务器状态和收听仪表板，可选择时间段。
- **主页**：新的“收听概览（新布局）”组件，可在主页 › 编辑中添加，带有分区面板；缩略图更大，并显示年份和流派。
- **曲库**：用“筛选”按钮固定您想要的筛选条件；古典音乐支持指挥、乐团 / 管弦乐团和作品；声道数和“立体声”筛选；按艺人所属国家的地图和筛选；音乐文件夹的“替换路径”；伪 Hi-Res 检测，默认关闭。
- **曲目技术信息**：频谱图和按声道的波形，曲库中的 Qobuz 和 TIDAL 曲目同样适用。
- **队列结束后的电台**：播放队列结束时，Tune 会继续播放相似曲目，并标记为“电台”；可按分区设置。
- **定时停止**：音乐在选定时间停止；在 Tune OS 上，机器也可以随之关机。
- **播放列表**：每一行显示播放次数和最后播放时间；“移除”叉号和“从此播放列表中删除”；可从您自己的 Qobuz 播放列表中移除曲目。
- **电台**：无损、高品质和 Hi-Res 筛选排在一行；目录中的电台可仅为您修改；电台可添加到播放列表。
- **播放**：Linux 本地输出（ALSA）支持原生 DSD；每个分区可固定 PCM 采样率；独占模式按分区设置；已删除的分区可恢复；对 CD 进行真正的 AccurateRip 校验。
- **DLNA**：为衔接两首曲目效果不佳的渲染器提供曲目间的连续流，默认关闭；组的主音量可从任意成员调节。
- **流媒体**：可选择 TIDAL 目录所属国家；Qobuz 新品与 Qobuz 播放器一致；Spotify 提供连接向导，Spotify Connect 在所选分区播放。
- **信号路径**：点击某个处理环节即可打开其设置；分组播放会显示每个输出。
- **设置与界面**：按设置项搜索、文字大小、波形进度条、所有界面统一的单一搜索框、助手中的语音输入。

## 改进

- **速度**：在大型曲库上，智能合集和字母跳转快得多；大型列表不再拖慢服务器。
- **内存**：长时间收听期间，Tune 会归还已释放的内存；转码占用的内存有上限。
- **起播速度**：YouTube 起播更快；在本地或 OAAT 输出上，TIDAL 不再等待整首曲目下载完毕。
- **统计**：所有界面使用同一个曲目和专辑总数，每种编解码器只有一项，可在整个排行榜中搜索。
- **Tune Circle**：消息支持表情符号；当联系人处的收听关闭时，Tune 会在您自己的来源中查找同一首曲目。
- **移动应用**：CarPlay 直接在手机上播放，带有合集和“电台”标签页；Android 新增 TIDAL 目录、电台和播客历史，以及“收藏的电台”小组件。
- **Windows**：防火墙过滤 Tune 时会显示横幅提示；本地分区显示 WASAPI 或 ASIO 徽标。
- **Docker**：SMB 共享向导可在镜像中使用；CD 驱动器可在容器中使用。
- **翻译**：15 种语言的复数形式均已正确。
- **依赖项**已更新，包括内置的 SQLite 3.54。

## 修复

- **网页界面**：界面更新后不再出现黑屏。
- **静音**：静音的分区在开始新曲目时保持无声；闹钟或音量上限不再解除静音。
- **播放**：损坏的文件不再使分区卡住，Tune 会继续播放后面的内容；已播完的播客单集不再在结尾处重新打开。
- **AirPlay 2**：暂停后从停止处继续播放，并以分区音量开始，绝不会以最大音量开始。
- **DLNA 和分组**：发生 701 错误后恢复播放；提前准备下一首曲目；无响应的设备不再阻塞其他分区；Sonos 使用其型号名称。
- **HQPlayer、Devialet 和 Diretta**：跟踪播放位置和状态，自动重新连接；Devialet 功放重新响应；Diretta 上不再显示无效的音量滑块。
- **OAAT**：原生 DSD 正确显示且比特完美；可识别 DSD1024，在能力受限的接收端回退为 PCM。
- **电台**：不再有重复的电台；在您所在国家被拒绝的电台会切换到下一个码流。
- **Spotify、Qobuz 和 TIDAL**：Spotify 播放列表和收藏遵循新 API；Qobuz 的拒绝不再显示为凭据错误；TIDAL 预加载不再延迟播放。
- **曲库**：按曲目统计收听次数；连字符不再产生虚假的艺人；套装中的各张碟识别得更准确；没有年份的曲目采用其专辑的年份。
- **Windows**：DAC 不在时不再把声音送到电脑扬声器；文件夹监视也覆盖网络共享。
- **PostgreSQL 18**：UPnP 收藏恢复正常。

## 安全

- 现在从网络中的另一台机器管理 Tune 需要登录（Tune OS：自新镜像起生效）。
- Webhook 不能再以 Tune 机器本身为目标。
- 配置 Home Assistant 和 Hue 需要管理员权限，或在 Tune 机器本身上进行；不再支持与 Tune 安装在同一台机器上的 Home Assistant。

## 已知问题

- **本地输出上的 DoP 方式 DSD**：在经过衰减的 PCM 之后，它可能以满量程播放，而不考虑音量。从 PCM 曲目切换到 DoP 方式的 DSD 曲目时，请将功放音量保持在较低水平（下一版本）。
- **完整性审核**：许多 FLAC 可能被错误地报告为已损坏；切勿仅凭这一结论删除任何文件。
- **由其他服务器驱动的 Windows ASIO**：暂停后再播放时没有声音；请跳到下一首曲目。
- **更新之后**：如果界面没有变化，请强制重新加载（Cmd+Shift+R 或 Ctrl+Shift+R）。首次启动需要更长时间，以便创建两个索引。
