Tune 1.0.0-rc13.2, Korrekturversion der rc13.1.

## Fehlerbehebungen

- Anmeldung: Das Passwort des Administratorkontos wird auf dem Server-Rechner und im lokalen Netzwerk auf dieselbe Weise geprüft; klarere Fehlermeldung (Benutzername: default).
- Wenn Sie sich nicht mehr anmelden können, verwenden Sie den Benutzernamen default und das zuletzt auf dem Server-Rechner eingegebene Passwort.
- Das mozaiklabs.fr-Konto kann jetzt von jedem Browser im lokalen Netzwerk (iPad, Telefon) verknüpft werden, solange noch kein Konto verknüpft ist.
- Windows: Die integrierte Aktualisierung bricht beim Bereitstellen der mitgelieferten Plugins (plugins.new\party) nicht mehr mit „Zugriff verweigert“ ab. Ein Plugin, das nicht ersetzt werden kann, behält seine Version, und die Aktualisierung wird trotzdem durchgeführt.
- Windows mit rc13 oder rc13.1: Die Aktualisierungsschaltfläche dieser Versionen bleibt blockiert. Installieren Sie diese Version mit dem Installationsprogramm (setup.exe), oder beenden Sie Tune und entpacken Sie das ZIP-Archiv über den Installationsordner. Spätere Aktualisierungen funktionieren wieder über die Schaltfläche.
