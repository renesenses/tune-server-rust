Tune 1.0.0-rc13.2, version corrective de la rc13.1.

## Corrections

- Connexion : le mot de passe du compte administrateur est vérifié de la même façon sur la machine du serveur et sur le réseau local ; message d'erreur plus clair (identifiant : default).
- Si vous ne pouvez plus vous connecter, utilisez l'identifiant default et le dernier mot de passe saisi sur la machine du serveur.
- Le compte mozaiklabs.fr peut maintenant être relié depuis n'importe quel navigateur du réseau local (iPad, téléphone), quand aucun compte n'est encore relié.
- Windows : la mise à jour intégrée ne s'arrête plus sur « Accès refusé » en posant les greffons livrés (plugins.new\party). Un greffon qui ne peut pas être remplacé garde sa version, et la mise à jour se fait quand même.
- Windows en rc13 ou rc13.1 : le bouton de mise à jour de ces versions reste bloqué. Installez cette version avec l'installateur (setup.exe), ou fermez Tune et décompressez l'archive zip par-dessus le dossier d'installation. Les mises à jour suivantes repasseront par le bouton.
