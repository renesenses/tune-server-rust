Tune 1.0.0-rc13.2, version corrective de la rc13.1.

## Corrections

- Connexion : un mot de passe erroné saisi sur la machine du serveur n'est plus accepté ni enregistré ; le message d'erreur dit maintenant « identifiant ou mot de passe incorrect » (identifiant administrateur : default).
- Si vous ne pouvez plus vous connecter, utilisez l'identifiant default et le dernier mot de passe saisi sur la machine du serveur.
