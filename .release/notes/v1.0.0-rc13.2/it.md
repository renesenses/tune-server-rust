Tune 1.0.0-rc13.2, versione correttiva della rc13.1.

## Correzioni

- Accesso: la password dell'account amministratore viene verificata allo stesso modo sulla macchina del server e sulla rete locale; messaggio di errore più chiaro (nome utente: default).
- Se non riesci più ad accedere, usa il nome utente default e l'ultima password inserita sulla macchina del server.
- L'account mozaiklabs.fr ora può essere collegato da qualsiasi browser della rete locale (iPad, telefono) quando non è ancora collegato alcun account.
- Windows: l'aggiornamento integrato non si interrompe più con «Accesso negato» durante la preparazione dei plugin inclusi (plugins.new\party). Un plugin che non può essere sostituito mantiene la sua versione, e l'aggiornamento viene eseguito comunque.
- Windows con rc13 o rc13.1: il pulsante di aggiornamento di quelle versioni resta bloccato. Installa questa versione con il programma di installazione (setup.exe), oppure chiudi Tune ed estrai l'archivio zip sopra la cartella di installazione. Gli aggiornamenti successivi funzioneranno di nuovo dal pulsante.
