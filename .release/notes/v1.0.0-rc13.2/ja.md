Tune 1.0.0-rc13.2、rc13.1 の修正版です。

## 修正

- サインイン：管理者アカウントのパスワードは、サーバーのマシンでもローカルネットワークでも同じ方法で確認されます。エラーメッセージもわかりやすくなりました（ユーザー名：default）。
- サインインできなくなった場合は、ユーザー名 default と、サーバーのマシンで最後に入力したパスワードを使用してください。
- アカウントがまだ連携されていない場合、mozaiklabs.fr アカウントをローカルネットワーク上の任意のブラウザ（iPad、スマートフォン）から連携できるようになりました。
- Windows：同梱プラグインの準備中（plugins.new\party）に「アクセスが拒否されました」で内蔵アップデートが止まらなくなりました。置き換えられないプラグインは現在のバージョンのまま残り、アップデート自体は実行されます。
- rc13 または rc13.1 の Windows：これらのバージョンのアップデートボタンは引き続き失敗します。このバージョンはインストーラー（setup.exe）でインストールするか、Tune を終了して zip アーカイブをインストールフォルダーに上書き展開してください。以降のアップデートは再びボタンから行えます。
