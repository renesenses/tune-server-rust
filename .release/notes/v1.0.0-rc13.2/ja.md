Tune 1.0.0-rc13.2、rc13.1 の修正版です。

## 修正

- サインイン：管理者アカウントのパスワードは、サーバーのマシンでもローカルネットワークでも同じ方法で確認されます。エラーメッセージもわかりやすくなりました（ユーザー名：default）。
- サインインできなくなった場合は、ユーザー名 default と、サーバーのマシンで最後に入力したパスワードを使用してください。
- アカウントがまだ連携されていない場合、mozaiklabs.fr アカウントをローカルネットワーク上の任意のブラウザ（iPad、スマートフォン）から連携できるようになりました。
- ローカルネットワークから同じアカウントを再接続することもできます。別のアカウントへの置き換えや連携の解除は、引き続きサーバーのマシンまたは管理者のみが行えます。連携中のアカウントの名前とメールアドレスは、ローカルネットワークから表示されます。
- Windows：Tune からのアップデートが再び機能するようになりました。rc13 と rc13.1 以降は、インストーラーを使う必要がありました。
- rc12 の Tune OS がアップデートできなくなった場合：ツール「Débloquer Tune」（Windows、macOS）を使えば、コマンドなしでアップデートを再開できます。別途ダウンロードしてください：https://github.com/renesenses/tune-server-rust/releases/tag/debloquer-tune-v1
