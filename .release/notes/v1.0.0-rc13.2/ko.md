Tune 1.0.0-rc13.2, rc13.1의 수정 릴리스입니다.

## 수정

- 로그인: 관리자 계정 비밀번호를 서버 컴퓨터와 로컬 네트워크에서 같은 방식으로 확인합니다. 오류 메시지도 더 명확해졌습니다(사용자 이름: default).
- 로그인할 수 없다면 사용자 이름 default와 서버 컴퓨터에서 마지막으로 입력한 비밀번호를 사용하세요.
- 아직 연결된 계정이 없으면 이제 로컬 네트워크의 모든 브라우저(iPad, 휴대전화)에서 mozaiklabs.fr 계정을 연결할 수 있습니다.
- Windows: 기본 제공 플러그인을 준비하는 중(plugins.new\party) 내장 업데이트가 더 이상 "액세스가 거부되었습니다"로 멈추지 않습니다. 교체할 수 없는 플러그인은 현재 버전을 유지하고, 업데이트는 그대로 진행됩니다.
- rc13 또는 rc13.1의 Windows: 해당 버전의 업데이트 버튼은 계속 막혀 있습니다. 이 버전은 설치 프로그램(setup.exe)으로 설치하거나, Tune을 종료한 뒤 zip 압축 파일을 설치 폴더에 덮어써서 풀어 주세요. 이후 업데이트는 다시 버튼으로 할 수 있습니다.
