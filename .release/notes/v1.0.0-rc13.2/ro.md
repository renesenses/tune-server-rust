Tune 1.0.0-rc13.2, versiune corectivă a rc13.1.

## Corecturi

- Conectare: parola contului de administrator este verificată la fel pe mașina serverului și în rețeaua locală; mesaj de eroare mai clar (nume de utilizator: default).
- Dacă nu vă mai puteți conecta, folosiți numele de utilizator default și ultima parolă introdusă pe mașina serverului.
- Contul mozaiklabs.fr poate fi acum asociat din orice browser din rețeaua locală (iPad, telefon), când încă nu este asociat niciun cont.
- Windows: actualizarea integrată nu se mai oprește la „Acces refuzat” când pregătește pluginurile incluse (plugins.new\party). Un plugin care nu poate fi înlocuit își păstrează versiunea, iar actualizarea se face oricum.
- Windows cu rc13 sau rc13.1: butonul de actualizare din aceste versiuni rămâne blocat. Instalați această versiune cu programul de instalare (setup.exe) sau închideți Tune și dezarhivați arhiva zip peste dosarul de instalare. Actualizările următoare vor funcționa din nou din buton.
