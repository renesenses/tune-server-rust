Tune 1.0.0-rc13.2, en rättningsversion av rc13.1.

## Rättningar

- Inloggning: ett felaktigt lösenord som anges på serverdatorn godtas inte längre och sparas inte; felmeddelandet säger nu ”felaktigt användarnamn eller lösenord” (administratörens användarnamn: default).
- Om du inte längre kan logga in, använd användarnamnet default och det senaste lösenordet som angavs på serverdatorn.
