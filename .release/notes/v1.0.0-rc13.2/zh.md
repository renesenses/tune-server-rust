Tune 1.0.0-rc13.2，rc13.1 的修正版本。

## 修复

- 登录：管理员账户的密码在服务器所在机器和局域网中以相同方式验证；错误提示更清晰（用户名：default）。
- 如果无法再登录，请使用用户名 default 以及最后一次在服务器所在机器上输入的密码。
- 在尚未关联任何账户时，现在可以从局域网内的任意浏览器（iPad、手机）关联 mozaiklabs.fr 账户。
- Windows：内置更新在准备随附插件（plugins.new\party）时不再因“拒绝访问”而中止。无法替换的插件将保留当前版本，更新仍会照常完成。
- 运行 rc13 或 rc13.1 的 Windows：这些版本的更新按钮仍然无法完成更新。请使用安装程序（setup.exe）安装此版本，或关闭 Tune 后将 zip 压缩包解压覆盖到安装文件夹。之后的更新将可以再次通过按钮完成。
