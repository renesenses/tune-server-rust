Tune 1.0.0-rc13.90: **rc14 사전 릴리스(pre-release)**, 테스터 전용입니다. 정식 공개 버전이 아니며, 자동 업데이트로 제공되지 않습니다. 테스트해 주시는 모든 분께 감사드립니다.

## 새로운 기능

- **TESS, 64비트 처리 체인**: 모든 처리를 처음부터 끝까지 64비트 부동소수점으로 수행하며, 양자화는 맨 마지막에 한 번만 합니다.
- **모든 출력에 같은 경로**: 로컬 출력, UPnP/DLNA, AirPlay, Devialet AIR, OAAT 모두 TESS를 거칩니다. 처리를 받을 수 없는 출력은 이를 분명히 알려 줍니다.
- **파라메트릭 이퀄라이저**: 자유 대역(주파수, 게인, Q), 그래픽 이퀄라이저 및 헤드폰 이퀄라이저(AutoEq 프로필)와 함께 제공됩니다.
- **컨볼루션**: .wav, .zip 압축 파일 또는 Convolver 설정(.cfg) 필터, 샘플링 레이트별 필터 1개, 끊김 없는 전환과 지연 시간 표시.
- **측정 기반 룸 보정**: 여러 청취 위치에서 계산한 혼합 위상 FIR 필터.
- **DSD 업샘플링**(DSD64, DSD128, DSD256), 시그마-델타 변조기 사용.
- **체인 프리셋**: 전체 체인을 저장하고 즉시 또는 다음 재생 시 불러올 수 있습니다.
- **신호 경로**: 재생 바에서 단계별로 실제로 무엇이 적용되는지, 어떤 단계가 왜 적용되지 않는지 보여 줍니다.
- **네이티브 플러그인**을 체인에: 실행 중 활성화, 64비트 형식, 채널 순서와 개수 유지.
- **20개 언어 인터페이스**: 네덜란드어, 번체 중국어, 러시아어, 우크라이나어 추가.
- **인증**: 설정 › 시스템 › 인증에 "인증 끄기" 버튼.

## 개선

- **SACD ISO**: 네이티브 DSD를 가상 DSF로 네트워크 플레이어에 제공합니다. DoP로 전송되는 DSD는 DSD로 표시됩니다.
- **원격 감상**: 5G에서 첫 트랙을 FLAC으로 보냅니다.
- **부재 중인 기기**: 30일 후 자동으로 잊힙니다(조정 가능). 존은 절대 삭제되지 않습니다.
- **Cover+**: 웹 라디오를 포함해 더 나은 커버 이미지(ICY 메타데이터).
- **그룹 재생**: 존별 오프셋 조정, 리더 존에서 "이전"을 누르면 팔로워 존도 다시 시작합니다.
- **라이브러리와 스트리밍**: 백그라운드 작업이 더 이상 인터페이스를 막지 않고, 앨범의 알파벳순 정렬이 유지되며, 서비스의 아티스트 페이지에서 비슷한 아티스트를 볼 수 있습니다.
- **거부 메시지**가 더 짧아지고 올바른 설정을 안내합니다.

## 수정

- **rc13.1과 rc13.2의 수정 사항** 포함: 관리자 계정 로그인, 로컬 네트워크에서 mozaiklabs.fr 계정 연결, 인증 사용 시 커버 이미지, Windows 업데이트.
- **UPnP**: Tune이 더 이상 자기 자신을 색인하지 않습니다. 색인된 트랙은 해당 서버의 현재 주소에서 재생됩니다.
- **재생**: 버퍼를 버리지 않는 30초 미리 불러오기, 소스가 거부한 탐색이 더 이상 스트림을 어긋나게 하지 않습니다.
- **Chromecast**가 다시 연결됩니다. AirPlay 재게시가 더 이상 재생을 끊지 않습니다.
- **팟캐스트**: 사용할 수 없는 에피소드를 올바르게 표시합니다.
- **포럼 제보**: 기록, Qobuz, Spotify, "뒤로" 버튼, 검색, iPad.

## 동작 변경

- **파라메트릭 이퀄라이저**: rc13까지 무료였으나 이제 컨볼루션, 룸 보정, 실시간 declick, 서드파티 플러그인과 마찬가지로 Tune Premium에 포함됩니다. 그래픽 이퀄라이저, 헤드폰 이퀄라이저, crossfeed는 계속 무료입니다.

## 직접 확인해 주세요

- **완전한 TESS 체인**(이퀄라이저, crossfeed, 컨볼루션 또는 룸 보정): 신호 경로가 들리는 소리와 일치합니까?
- **컨볼루션 세트 가져오기**와 재생 중 필터 전환.
- **DSD 업샘플링**(호환 DAC): 안정성, 레벨, 클릭 잡음 여부.
- **체인 프리셋**, 두 가지 적용 방식 모두.
- **네트워크 출력**(UPnP, AirPlay 또는 OAAT)에서 처리를 켠 상태.
- **rc13.x에서 업데이트**와 "인증 끄기" 버튼.

## 알려진 문제

- **DST로 압축된 SACD**: 이 ISO 이미지는 아직 네이티브로 재생되지 않습니다.
- **VU 미터**: 중계된 MP3, AAC 또는 Ogg 트랙에서 탐색한 뒤 트랙이 끝날 때까지 꺼집니다. 소리에는 영향이 없습니다.
- **CarPlay 원격 감상**: 릴레이 수정은 rc15로 연기되었습니다.
- **화면 없는 서버에서 인증을 끈 경우**: 연결된 mozaiklabs.fr 계정을 바꾸려면 인증을 켜거나 localhost:8888로 SSH 터널을 사용하세요.
