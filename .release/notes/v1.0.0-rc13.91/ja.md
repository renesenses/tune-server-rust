Tune 1.0.0-rc13.91：**rc14 の 2 つ目のプレリリース（pre-release）**、テスター専用です。公開版ではありません。自動アップデートでは提供されません。rc13.90 の内容をすべて含んでいます。テストにご協力いただいている皆さまに感謝します。

## 新機能

- **直列に組み合わせられるイコライザー**：グラフィックイコライザー、パラメトリックイコライザー、ヘッドホンイコライザー、ルーム補正が同じ TESS チェーンの中で順につながります。ルーム補正を適用しても、ほかのイコライザーが上書きされなくなりました。パラメトリックイコライザーのゲイン範囲を広げました。
- **完全な Bypass all**：ひとつの操作で TESS チェーン全体を回路から外し、元どおりに戻せます。
- **ヘッドホンプラグイン**：OPRA データベースをもとに、お使いのヘッドホンのプロファイルを認識し、プリアンプとレベルも設定します。
- **Speaker Setup プラグイン**（スピーカー設定）：チャンネルごとに距離、ゲイン、位相を調整します。
- **ローカル出力での DSD へのアップサンプリング**：専用のシグマデルタ変調器を使い、出力の DSD 対応能力も公開します。
- **アップサンプリング先を選択可能**：TESS の画面で、アップサンプリング先を PCM と DSD から選べます。
- **マイクのレベルテスト**：ルーム測定の前に行います。
- **マイクのネイティブサンプルレートでの測定**：44.1 から 192 kHz まで。
- **TESS の設定をその場で変更**：段を無効にするとすぐに反映され、プリアンプは上限を超えません。

## 改善

- **ルーム補正**：検証測定でゾーンの補正が反映された音を測ります。補正されなかった差には説明が付き、上限は 1 kHz まで調整できます。
- **ルーム補正**：画面に戻ると、入力内容、最後の測定、適用中の補正が復元されます。マイクの配置の指示と「測定の前に」の枠が測定を案内します。
- **PURE モードでの測定**：スイープの間は音量を 100 % に固定し、終わると元の値に戻します。
- **信号経路**：オフになっている段（アップサンプリング、コンボリューション）が、TESS とプラグインのページでその理由を示します。Windows の共有モードでは、アップサンプリングはミキサーのサンプルレートを目標にします。
- **クレジット**：「ミュージシャン」ではなく楽器名を表示し、作詞者と作曲者を区別し、役割ごとに名前を 1 つにします。
- **スキャン**：タグに含まれるバーコードで、バーコードのないアルバムを補完します。
- **サーバーの状態**：ジャケット画像のキャッシュを作成できない場合に警告を表示します。

## 修正

- **キャリブレーション**：スイープが告知した長さより前に止まらなくなり、キューで止まったままにもならなくなりました。出力のないゾーンははっきりと拒否されます。
- **キャリブレーション**：上限に達したピークが、それ以降のバンドを妨げなくなりました。
- **RT60**：誤った値ではなく「測定不能（ノイズ）」と表示します。エラーメッセージは少なくとも 10 秒間表示されます。
- **サンプルレートの警告**：受け付けられるサンプルレートの範囲外でのみ表示されるようになりました。
- **ラジオ**：局の切り替えが前の局で上書きされなくなりました。
- **ジャケット画像**：新規インストールでは、キャッシュがデータフォルダーの下に作成されます。
- **TESS**：「次の曲」の通知は 1 回だけになり、「適用」ボタンのヘルプを修正しました。

## 動作の変更

- **再生中の TESS チェーンの変更**：無効にした段はすぐに止まります。追加した段や再び有効にした段は、次の再生から聞こえます。

## お手元でご確認ください

これらの項目は、まだ実機でテストされていません：

- **実際の DSD DAC での DSD へのアップサンプリング**：安定性、レベル、クリックノイズの有無。
- **44.1 kHz と 96 kHz でのルーム測定**：実際のオーディオインターフェースで、マイクのレベルテストも含めて。
- **Windows の WASAPI 共有モード**：再生とアップサンプリング。
- **ネットワーク出力での Speaker Setup**（UPnP、AirPlay、OAAT）：距離、ゲイン、位相。

また：

- **複数のイコライザーの直列接続**と Bypass all：信号経路は聞こえている音と一致していますか？
- **ヘッドホンプラグイン**をご自分のヘッドホンで。
- **rc13.90 からのアップデート。**

## 既知の問題

- **DST 圧縮の SACD**：これらの ISO イメージはまだネイティブ再生できません。
- **VU メーター**：中継された MP3、AAC、Ogg の曲でシークすると、曲の終わりまで消えます。音には影響しません。
- **CarPlay でのリモート再生**：リレーの修正は rc15 に延期されました。
- **画面のないサーバーで認証が無効の場合**：リンクされた mozaiklabs.fr アカウントを変更するには、認証を有効にするか、localhost:8888 への SSH トンネルを使用してください。
