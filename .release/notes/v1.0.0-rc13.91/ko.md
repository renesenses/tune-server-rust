Tune 1.0.0-rc13.91: **rc14의 두 번째 사전 릴리스(pre-release)**, 테스터 전용입니다. 정식 공개 버전이 아니며, 자동 업데이트로 제공되지 않습니다. rc13.90의 모든 내용을 포함합니다. 테스트해 주시는 모든 분께 감사드립니다.

## 새로운 기능

- **직렬로 조합할 수 있는 이퀄라이저**: 그래픽 이퀄라이저, 파라메트릭 이퀄라이저, 헤드폰 이퀄라이저, 룸 보정이 같은 TESS 체인 안에서 차례로 이어집니다. 룸 보정을 적용해도 더 이상 다른 이퀄라이저를 덮어쓰지 않습니다. 파라메트릭 이퀄라이저의 게인 범위가 넓어졌습니다.
- **완전한 Bypass all**: 한 번의 동작으로 TESS 체인 전체를 회로에서 빼고, 그대로 다시 되돌립니다.
- **헤드폰 플러그인**: OPRA 데이터베이스를 바탕으로 사용 중인 헤드폰의 프로필을 인식하며, 프리앰프와 레벨도 함께 적용합니다.
- **Speaker Setup 플러그인**(스피커 설정): 채널별로 거리, 게인, 위상을 조정합니다.
- **로컬 출력에서 DSD 업샘플링**: 전용 시그마-델타 변조기를 사용하며, 출력의 DSD 지원 능력을 공개합니다.
- **업샘플링 대상 선택**: TESS의 화면에서 업샘플링 대상을 PCM 또는 DSD 중에서 선택할 수 있습니다.
- **마이크 레벨 테스트**: 룸 측정 전에 진행합니다.
- **마이크의 기본 샘플링 레이트로 측정**: 44.1~192kHz.
- **TESS 설정 즉시 변경**: 단계를 끄면 바로 적용되며, 프리앰프는 한계를 넘지 않습니다.

## 개선

- **룸 보정**: 검증 측정에서 해당 존의 보정이 적용된 소리를 듣습니다. 보정되지 않은 차이는 설명이 붙으며, 상한은 1kHz까지 조정할 수 있습니다.
- **룸 보정**: 화면으로 돌아오면 입력 내용, 마지막 측정, 적용된 보정이 그대로 복원됩니다. 마이크 배치 안내와 "측정 전에" 안내 상자가 측정을 도와줍니다.
- **PURE 모드에서 측정**: 스윕하는 동안 볼륨을 100%로 고정하고, 끝나면 원래대로 되돌립니다.
- **신호 경로**: 꺼진 단계(업샘플링, 컨볼루션)가 TESS와 플러그인 페이지에서 그 이유를 알려 줍니다. Windows 공유 모드에서는 업샘플링이 믹서의 샘플링 레이트를 목표로 합니다.
- **크레디트**: "뮤지션" 대신 악기를 표시하고, 작사가와 작곡가를 구분하며, 역할마다 이름 하나씩 표시합니다.
- **스캔**: 태그에 있는 바코드로 바코드가 없는 앨범을 보완합니다.
- **서버 상태**: 커버 이미지 캐시를 만들 수 없으면 경고를 표시합니다.

## 수정

- **캘리브레이션**: 스윕이 안내된 길이보다 먼저 멈추지 않고, 대기열에 걸려 있지도 않습니다. 출력이 없는 존은 분명하게 거부됩니다.
- **캘리브레이션**: 상한에 닿은 피크가 더 이상 다음 대역을 막지 않습니다.
- **RT60**: 잘못된 값 대신 "측정 불가(잡음)"로 표시합니다. 오류 메시지는 최소 10초 동안 읽을 수 있게 남습니다.
- **샘플링 레이트 경고**: 허용되는 샘플링 레이트를 벗어날 때만 나타납니다.
- **라디오**: 방송국을 바꿔도 이전 방송국에 덮어쓰이지 않습니다.
- **커버 이미지**: 새로 설치한 경우 캐시가 데이터 폴더 아래에 만들어집니다.
- **TESS**: "다음 트랙" 알림이 한 번만 나오며, "적용" 버튼의 도움말이 수정되었습니다.

## 동작 변경

- **재생 중 TESS 체인 변경**: 비활성화한 단계는 즉시 꺼집니다. 추가하거나 다시 활성화한 단계는 다음 재생부터 들립니다.

## 직접 확인해 주세요

다음 항목은 아직 실제 하드웨어에서 테스트되지 않았습니다:

- **실제 DSD DAC에서 DSD 업샘플링**: 안정성, 레벨, 클릭 잡음 여부.
- **44.1kHz와 96kHz에서 룸 측정**: 실제 오디오 인터페이스로, 마이크 레벨 테스트와 함께.
- **Windows의 WASAPI 공유 모드**: 재생과 업샘플링.
- **네트워크 출력에서 Speaker Setup**(UPnP, AirPlay 또는 OAAT): 거리, 게인, 위상.

그리고:

- **여러 이퀄라이저 직렬 연결**과 Bypass all: 신호 경로가 들리는 소리와 일치합니까?
- **헤드폰 플러그인**을 직접 사용하는 헤드폰으로.
- **rc13.90에서 업데이트.**

## 알려진 문제

- **DST로 압축된 SACD**: 이 ISO 이미지는 아직 네이티브로 재생되지 않습니다.
- **VU 미터**: 중계된 MP3, AAC 또는 Ogg 트랙에서 탐색한 뒤 트랙이 끝날 때까지 꺼집니다. 소리에는 영향이 없습니다.
- **CarPlay 원격 감상**: 릴레이 수정은 rc15로 연기되었습니다.
- **화면 없는 서버에서 인증을 끈 경우**: 연결된 mozaiklabs.fr 계정을 바꾸려면 인증을 켜거나 localhost:8888로 SSH 터널을 사용하세요.
