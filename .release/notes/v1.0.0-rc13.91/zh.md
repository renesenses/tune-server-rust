Tune 1.0.0-rc13.91：**rc14 的第二个预发布版（pre-release）**，仅供测试人员使用。这不是正式发布的版本：自动更新不会提供它。它包含 rc13.90 的全部内容。感谢所有参与测试的朋友。

## 新功能

- **可串联组合的均衡器**：图形均衡器、参数均衡器、耳机均衡器和房间校正在同一条 TESS 处理链中依次衔接；应用房间校正不再覆盖其他均衡器。参数均衡器的增益范围已扩大。
- **完整的 Bypass all**：一个操作即可让整条 TESS 处理链脱离回路，并原样恢复。
- **耳机插件**，数据取自 OPRA 数据库：自动识别您耳机的配置文件，包含前级增益和电平。
- **Speaker Setup 插件**（扬声器设置）：逐声道调整距离、增益和相位。
- **本地输出升频至 DSD**：专用的 sigma-delta 调制器，并公布输出的 DSD 能力。
- **可选择升频目标**：在 TESS 中，可在一个界面里选择升频至 PCM 还是 DSD。
- **麦克风电平测试**，在房间测量之前进行。
- **以麦克风的原生采样率测量**，从 44.1 到 192 kHz。
- **即时调整 TESS 设置**：停用某一级会立即生效，前级增益始终保持在限定范围内。

## 改进

- **房间校正**：验证测量会听到该区域的校正效果；未被校正的偏差会给出解释，上限可调至 1 kHz。
- **房间校正**：返回该页面时，输入的内容、最近一次测量和已应用的校正都会恢复；麦克风摆放说明和“测量之前”提示框会引导测量。
- **PURE 模式下的测量**：扫频期间音量强制设为 100%，结束后恢复原值。
- **信号路径**：被关闭的环节（升频、卷积）会在 TESS 和插件页面中说明原因；在 Windows 共享模式下，升频以混音器的采样率为目标。
- **演职人员信息**：显示具体乐器而不是“乐手”，作者与作曲者分开显示，每个角色一个名字。
- **扫描**：标签中的条形码会补全尚无条形码的专辑。
- **服务器状态**：如果无法创建封面缓存，会显示警告。

## 修复

- **校准**：扫频不再在标示的长度之前停止，也不再卡在队列中；没有输出的区域会被明确拒绝。
- **校准**：触顶的峰值不再阻塞后续频段。
- **RT60**：显示“无法测量（噪声）”而不是错误的数值；错误信息至少保留 10 秒以便阅读。
- **采样率警告**：只在超出可接受的采样率时才出现。
- **电台**：切换电台不再被旧电台覆盖。
- **封面**：在全新安装中，缓存创建在数据文件夹下。
- **TESS**：“下一首”提示只出现一次，“应用”按钮的帮助说明已更正。

## 行为变化

- **播放时更改 TESS 处理链**：被停用的一级立即关闭；新增或重新启用的一级从下一次播放开始生效。

## 请在您的环境中验证

这些项目尚未在真实硬件上测试：

- **在真正的 DSD DAC 上升频至 DSD**：稳定性、电平、无爆音。
- **44.1 kHz 和 96 kHz 下的房间测量**，使用真实的音频接口，并配合麦克风电平测试。
- **Windows 下的 WASAPI 共享模式**：播放和升频。
- **网络输出上的 Speaker Setup**（UPnP、AirPlay 或 OAAT）：距离、增益和相位。

另外：

- **多个均衡器串联**并使用 Bypass all：信号路径与您听到的是否一致？
- **耳机插件**搭配您自己的耳机。
- **从 rc13.90 更新。**

## 已知问题

- **DST 压缩的 SACD**：这类 ISO 镜像尚不能原生播放。
- **VU 表**：在转发的 MP3、AAC 或 Ogg 曲目上跳转后，会关闭直到曲目结束。声音不受影响。
- **CarPlay 远程收听**：中继的修复推迟到 rc15。
- **无屏幕服务器且已关闭身份验证**：要更换关联的 mozaiklabs.fr 账户，请启用身份验证，或通过 SSH 隧道访问 localhost:8888。
