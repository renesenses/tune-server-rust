Tune 1.0.0-rc13、Tune 1.0 の 13 番目のリリース候補です。報告とテストをしてくださった Gros Bidon、r5yk5、Tades、cpadiou77、Pierre、Daniel LEVY、Lio、sashasha、ajm、Jean Valjean、Semakawa、Jon Rotaetxe、hifi25nl、aqs、Christopher J、FabienM、Begastor、Régis の皆さん、Smart Upsampler の alec_eiffel さん、Qobuz への貢献をくださった cometdom さん、デザインの Levente さんに感謝します。

## 新機能

- **アップサンプラー**: Rémi（alec_eiffel）さんが設計した Smart Upsampler は、使わないときと同じレベルで再生され、設定の変更はすぐに聴こえます。
- **再生と出力**: Sendspin と Devialet AIR に処理済みの音（イコライザー、プラグイン、アップサンプラー）が届きます。スリープタイマーでコンピューターの電源を切れます。Linux ではデスクトップのメディアコントロールに表示されます。
- **クロスフィード**: 設定とプリセットを含めて無料になりました。
- **コンボリューション**: サンプルレートごとに 1 つのインパルス応答ファイルを使えます。
- **DSD**: UPnP サーバーの DSD を要求の厳しいネットワークプレーヤーでネイティブ再生でき、2 つの DSD トラックが途切れなくつながります。
- **ライブラリ**: ファイルの個人用タグが Tune のタグになります。複数のアルバムを選んでまとめて操作でき、楽器フィルターが加わりました。
- **改変されたソース**: 「疑わしいハイレゾ」に代わり、すべてのフォーマットが対象で、測定されたカットオフを示します。
- **波形**: より細かくなり、CUE トラックにも、オプションで Qobuz と TIDAL のトラックにも表示されます。
- **キュー**: アルバムを折りたため、ひと操作で移動できます。
- **ホーム**: 「お気に入りのアーティストから…」の 5 つのプレイリストと、よく聴くアーティスト、よく聴くアルバム、後で聴く、続きから聴くのウィジェット。
- **サービス**: TIDAL の「あなたへのおすすめ」ページ。Qobuz ではジャンルごとに 200 件の新着。
- **Tune Circle**: 同意したメンバーは互いの姿が見え、「ワールド」ビューにはすべてのサークルが表示されます。
- **Web インターフェース**: トルコ語、インターフェースからの認証の有効化、トラックごとまたは再生ごとの履歴。
- **Tune Client（デスクトップアプリ）**: ネットワーク上のサーバーを自動で見つけ、ローカルサーバーを操作できます。
- **Windows**: インストーラーで、Windows と同時に Tune を起動するよう設定できます。
- **iOS アプリ**: 5G の CarPlay が充実し、iPad ではサイドバーが戻りました。

## 改善

- **トラック間のつながり**: 「自動」モードでは、同じアルバムの連続するトラック間で ReplayGain がアルバムゲインを適用します。AAC、Opus、CUE トラックが途切れなくつながります。
- **再生と出力**: AirPlay 1 と AirPlay 2 は同じ音量カーブを共有します。ネットワークプレーヤーでラジオがより速く始まります。
- **Windows**: WASAPI 排他モードで、Tune はトラックを止めずにもう一方のレート系列に切り替えます。
- **Devialet AIR**: 音量は 1 dB 刻み、最大 192 kHz。
- **DSD**: ネイティブ DSD の判定がより慎重になり、再評価されます。
- **大規模なライブラリ**: 「フォルダ」画面が待たずに開き、バックグラウンドのタスクがほかの処理を妨げなくなりました。
- **サービス**: YouTube は Tune 独自の Google ログインクライアントを使用します。Spotify と TIDAL は再生中により安定しました。
- **Web インターフェース**: パラメトリックイコライザーの精度が上がり、削除の前に確認が求められます。
- **iOS アプリ**: ロック画面から、再生していないときもゾーンを操作できます。DAC がない場合、スライダーで iOS の音量を調整します。
- **アップデートと診断**: 内蔵のアップデートは Tune に付属するプログラムも置き換えます。バグレポートでは名前が伏せられます。

## 修正

- **再生と出力**: 一時停止で DAC が解放されたあとも再開が機能します。「すべてリピート」が一時的な停止をトラックの終わりと取り違えなくなりました。Windows では、Tune のあとに電源を入れた DAC が見つかります。
- **ゾーン**: すでに紐付けられたデバイスはそのゾーン名を示します。OAAT では、再開すると無音のままにならずにセッションを開き直します。
- **DLNA、UPnP、OpenHome**: Musicbook Source が「停止」を挟まなくなり、ミュートが安定し、Linn Klimax DS/2 が認識されます。
- **AirPlay**: Tune の再起動後、AirPlay 1 出力が最大音量で始まらなくなりました。
- **信号経路**: 実際には行われていない処理を表示しなくなりました。
- **ライブラリ**: 同じアルバムの DSD 版と CD 版が統合されなくなりました。DR の書き込みでサーバーが固まらなくなりました。
- **サービス**: Qobuz と TIDAL のお気に入りに正しい長さが表示されます。Spotify の項目が重複しなくなりました。
- **ラジオ**: FIP の各局のロゴが戻りました。
- **プラグインとクロスフィード**: インストールしたプラグインは再起動なしで機能します。OAAT とブラウザーで、クロスフィードがロックされなくなりました。
- **Web インターフェース**: グリッドが最後までスクロールします。「サーバーが応答しません」のバナーはサーバーが応答するとすぐに消えます。

## セキュリティ

- 複数のセキュリティ強化を行いました。
- ログとバグレポートでは、一部のストリームのアドレスに含まれる認証情報が伏せられるようになりました。
- 「パスを置き換え」（設定 › 音楽フォルダー）は、フォルダーを確認するようになり、認証なしでは別のデバイスから利用できなくなりました。

## 動作の変更

- **Tune Circle**: 認証が有効な場合は管理者のみ。リモート再生からは読み取り専用です。
- **YouTube**: このバージョンより前に接続したアカウントは、一度接続し直す必要があります。
- **キュー終了後のラジオ**: 再び既定で無効になりました。選んでいた場合は、ゾーンの設定で再度チェックを入れてください。
- **イコライザー**: オフにしても、「レベルを戻す」までプリアンプは適用されたままです。
- **マルチルーム**: 再生グループは 3 つのゾーンまで無料で、それを超える場合は Premium が必要です。ステレオペアは引き続き無料です。
- **INDEX 02 を含む CUE**: トラックの開始位置は次回のスキャンで修正され、再生履歴は保持されます。
- **Tune OS**: 一時パスワードはログインページではなく、マシンの画面かブートカードに表示されます。変更するまでリモートアクセスは閉じたままです。
- **プロフィールと履歴**: 認証が有効な場合、ほかのプロフィールを管理できるのは管理者だけです。
- **パスを置き換え**: 認証がない場合、Tune が動作しているマシンから行います。

## 既知の問題

- **ローカル出力での DoP による DSD**: 減衰した PCM の後に、フルスケールで再生されることがあります。アンプの音量を低くしておいてください。
- **アドレス変更後の UPnP**: トラックが再生できないことがあります。そのサーバーのインデックスを作り直してください。
- **整合性監査**: 一部のファイルが誤って報告されることがあります。この判定だけでファイルを削除しないでください。
- **別のサーバーから制御される Windows ASIO**: 一時停止してから再生すると音が出ません。次のトラックに進んでください。
- **アップデート後**: インターフェースが変わらない場合は、強制的に再読み込みしてください（Cmd+Shift+R または Ctrl+Shift+R）。
