Tune 1.0.0-rc13，Tune 1.0 的第十三个候选版本。感谢 Gros Bidon、r5yk5、Tades、cpadiou77、Pierre、Daniel LEVY、Lio、sashasha、ajm、Jean Valjean、Semakawa、Jon Rotaetxe、hifi25nl、aqs、Christopher J、FabienM、Begastor 和 Régis 的报告和测试，感谢 alec_eiffel 带来 Smart Upsampler，感谢 cometdom 对 Qobuz 的贡献，感谢 Levente 的设计。

## 新功能

- **升频器**：由 Rémi（alec_eiffel）设计的 Smart Upsampler 以与关闭时相同的电平播放，更改设置后立即生效。
- **播放与输出**：Sendspin 和 Devialet AIR 接收经过处理的声音（均衡器、插件、升频器）。定时停止可以关闭电脑；在 Linux 上，Tune 会出现在桌面的媒体控制中。
- **交叉馈送**：现已免费，包括其设置和预设。
- **卷积**：每种采样率可使用一个脉冲响应文件。
- **DSD**：来自 UPnP 服务器的 DSD 可以在要求较高的网络播放器上原生播放，两首 DSD 曲目之间无缝衔接。
- **音乐库**：文件中的个人标签会变成 Tune 标签；可一次选择多张专辑进行批量操作；新增按乐器筛选。
- **音源受损**取代“可疑 Hi-Res”，适用于所有格式，并给出测得的截止频率。
- **波形**更精细，CUE 曲目也会显示，Qobuz 和 TIDAL 曲目可选。
- **播放队列**：专辑可以折叠，并可通过一个手势移动。
- **主页**：“因为你喜欢……”提供 5 个播放列表，并新增小组件：最常聆听的艺人、常听专辑、稍后收听和继续收听。
- **流媒体服务**：TIDAL 的“为你推荐”页面；Qobuz 每个流派 200 张新发行专辑。
- **Tune Circle**：共享圈子的成员在同意的情况下可以互相看到，“世界”视图显示所有圈子。
- **网页界面**：土耳其语、可在界面中启用身份验证，历史记录可按曲目或按播放显示。
- **Tune Client（桌面应用）**：自行找到网络中的服务器，并可控制本地服务器。
- **Windows**：安装程序提供随 Windows 启动 Tune 的选项。
- **iOS 应用**：5G 下的 CarPlay 更完善，iPad 侧边栏回来了。

## 改进

- **曲目衔接**：“自动”模式下，ReplayGain 在同一专辑的相邻曲目之间应用专辑增益；AAC、Opus 和 CUE 曲目无缝衔接。
- **播放与输出**：AirPlay 1 和 AirPlay 2 使用同一条音量曲线；电台在网络播放器上启动更快。
- **Windows**：在 WASAPI 独占模式下，Tune 会切换到另一采样率系列，而不是停止曲目。
- **Devialet AIR**：音量以 1 dB 为步进，最高 192 kHz。
- **DSD**：原生 DSD 的判断更加谨慎，并会重新评估。
- **大型音乐库**：“文件夹”屏幕打开时无需等待，后台任务不再阻塞其他操作。
- **流媒体服务**：YouTube 使用 Tune 自己的 Google 登录客户端；Spotify 和 TIDAL 在播放过程中更稳定。
- **网页界面**：参数均衡器更加精确，删除前会要求确认。
- **iOS 应用**：锁定屏幕即使在区域未播放时也能控制它；没有 DAC 时，滑块会调节 iOS 的音量。
- **更新与诊断**：内置更新也会替换随 Tune 提供的程序；错误报告会隐藏名称。

## 修复

- **播放与输出**：暂停释放 DAC 后继续播放恢复正常；“全部重复”不再把短暂停止误认为曲目结束；在 Windows 上，在 Tune 之后开启的 DAC 可被找到。
- **区域**：已关联的设备会说明是哪个区域；在 OAAT 下，继续播放会重新打开会话，而不是保持无声。
- **DLNA、UPnP 和 OpenHome**：Musicbook Source 不再插入“停止”，静音保持稳定，Linn Klimax DS/2 得到识别。
- **AirPlay**：Tune 重启后，AirPlay 1 输出不再以最大音量开始。
- **信号路径**：不再标示实际未进行的处理。
- **音乐库**：同一专辑的 DSD 版和 CD 版不再被合并；写入 DR 不再导致服务器卡死。
- **流媒体服务**：Qobuz 和 TIDAL 收藏显示正确时长；Spotify 的栏目不再重复。
- **电台**：FIP 各电台重新显示其标志。
- **插件与交叉馈送**：安装的插件无需重启即可生效；在 OAAT 上和浏览器中，交叉馈送不再被锁定。
- **网页界面**：网格可以一直滚动到底；“服务器无响应”横幅会在服务器响应后立即消失。

## 安全

- 多项安全加固。
- 日志和错误报告现在会隐藏部分流地址中携带的凭据。
- “替换路径”（设置 › 音乐文件夹）现在会检查文件夹，并且在未启用身份验证时无法再从其他设备访问。

## 行为变化

- **Tune Circle**：启用身份验证后仅限管理员；通过远程收听时为只读。
- **YouTube**：在此版本之前连接的账户需要重新连接一次。
- **队列结束后的电台**：再次默认关闭；如果您之前选择了它，请在区域设置中重新勾选。
- **均衡器**：关闭均衡器后，其前级放大保持生效，直到点击“恢复电平”。
- **多房间**：播放组在 3 个区域以内免费；超过需要 Premium。立体声配对仍然免费。
- **带有 INDEX 02 的 CUE**：曲目开头会在下次扫描时修正，收听历史会被保留。
- **Tune OS**：临时密码显示在机器的屏幕或启动卡上，不再显示在登录页面上；在更改之前，远程访问保持关闭。
- **配置文件与历史记录**：启用身份验证后，只有管理员可以管理其他配置文件。
- **替换路径**：未启用身份验证时，需在运行 Tune 的机器上进行。

## 已知问题

- **本地输出上的 DoP 方式 DSD**：在经过衰减的 PCM 之后，它可能以满量程播放。请将功放音量保持在较低水平。
- **地址变更后的 UPnP**：曲目可能无法播放；请重新为该服务器建立索引。
- **完整性审核**：少数文件仍可能被误报；切勿仅凭这一结论删除任何文件。
- **由其他服务器驱动的 Windows ASIO**：暂停后再播放时没有声音；请跳到下一首曲目。
- **更新之后**：如果界面没有变化，请强制重新加载（Cmd+Shift+R 或 Ctrl+Shift+R）。
