Tune 1.0.0-rc14 には、プレリリース rc13.90 と rc13.91 の内容がすべて含まれています。このノートでは rc13.91 からの変更点を説明します。テスターの皆さまに感謝します。これらの項目の多くは、皆さまのフィードバックから生まれました。

## 新機能

- **TESS のプリセットの保存と再読み込み**：設定が選択中のプリセットから外れるとすぐに、TESS に「変更あり」と表示されます。**保存**は元のプリセットを上書きし、**再読み込み**で元に戻ります。「Pure」など Tune に付属するプリセットは上書きできません。「名前を付けて保存…」でコピーを作成します。
- **TESS の DSD プリセットをすぐに適用**：DSD の目標を変えるプリセット（例：DSD128 → DSD256）を「すぐに適用」モードで読み込むと、次のトラックを待たずに、トラックを現在の位置から再開します。アップサンプリングは Premium 機能です。
- **ヘッドルーム**：自動、または −12 から 0 dB まで 0.5 dB 刻みの手動で設定します。パネルには実際に適用されている値が表示され、適用されていない場合はその理由が表示されます。
- **DSD へのアップサンプリング時のヘッドルーム**：手動のヘッドルームが二重に適用されなくなりました（以前は −12 dB が −24 dB になっていましたが、現在は −15 dB です。うち −3 dB は DSD 変調器の分で、専用の行に表示されます）。
- **75 dB(C) を目標にしたガイド付きルーム測定**：校正済みマイクを使うと、画面に測定レベル、75 dB(C) との差、音量の指示が表示されます。換算はまだ校正器で確認されていないため、ルールは慎重です。Tune は推定 80 dB(C) を超えるよう勧めることはなく、90 dB SPL で信号を遮断します。マイクで測定する補正は Premium、マイクなしで計算する補正は引き続き無料です。
- **聴覚の保護**：イコライザーのチェックを外す、PURE または Bypass all に切り替える、コンボリューション・クロスフィード・モノラル化を取り除く、といった操作でレベルが急に上がることはなくなりました。レベルは約 0.5 秒のフェードで以前のレベルに戻ります。その間に音量を上げていた場合は「レベル低減」のインジケーターが点灯し、「レベルを戻す」で増えた分を解除できます。ネットワーク出力（UPnP、OAAT）でも同様です。
- **実際どおりの信号経路**：
  - ネットワーク出力では、プレーヤーの音量まで、ストリームの実際の順序に従います。
  - インパルス応答フィルターの段は「コンボリューション」と呼ばれます。
  - フィルターは、読み込んだ .wav または .zip ファイルの名前を保ちます。
  - DSD の目標を変更した後は、実際に再生中の DSD レートを表示し、次のレートを予告します。
  - ウィンドウは緑で表示されます。オレンジは本当の警告だけに使います。
- **コンボリューション**：パネルに、読み込んだフィルターのカーブがチャンネルごとに表示され、位相も必要に応じて表示されます。
- **Bypass all**：TESS がバイパスされているとき、再生バーの TESS アイコンが淡く表示され、TESS のページには「TESS バイパス中」と表示されます。
- **統一された TESS のページ**：TESS の緑のアクセント、バッジの近くに現在のゾーン、ネットワーク出力ではグレー表示の Headroom パネル、そして「マイクなし（推定）」または「マイクあり（推奨）」の測定。
- **ネットワーク出力**：「アップサンプリング」カードに、ネットワーク出力ではアップサンプリングが適用されないことが表示されます。
- **統一されたインターフェース**：フォントを内蔵し、オフラインでも表示されます。ライブラリ、Live Radio、メディアサーバー、コンサートが新しいデザインに沿うようになりました。

## 修正

- **Sonos へのラジオ再生**（およびレートに上限のあるすべてのネットワークプレーヤー）：192 kHz のラジオ局が、プレーヤーが受け付けるレートで配信されます。以前は、プレーヤーがすぐに停止し、それが繰り返されていました。
- **768 kHz**：ゾーンの「最大周波数」のリストに 768 kHz と 1,536 kHz があります。
- **ライブラリ**：大きなコレクションをスクロールしている間に、アルバムのグリッドが固まらなくなりました。
- **ブラウザーのタブでの再生**：シーク操作で再生位置が実際に移動します。別のデバイスからの操作でも同様です。
- **ヘルプ**：Premium アカウントでは、優先サポートのバナーが表示されなくなりました。
- **ライセンス**：有効期限を正しく読み取ります。「設定 › ライセンス」では無料プランになっている理由も表示されます。
- **コンボリューション**：一部の周波数を持ち上げるフィルターでも、クリップしなくなりました。
- **長いポッドキャスト**：配信元が定期的に接続を切るエピソードでも、再生が止まらなくなりました。
- **LXC コンテナー内の Debian パッケージ**（Proxmox）：プライベートなマウント名前空間がなくても、サービスが起動します。
- **初回起動**：ウィザードは、アカウントのないサービスを「有効」と表示しなくなり、選んだ音楽フォルダーを保存します。「マイラジオ」が空のときは、ラジオ局のディレクトリが開きます。

## セキュリティとアカウント

- **更新されるセッション**：「ログインしたままにする」（初期設定ではオフ）を選ぶと、ブラウザーのセッションは使われている間、最長 90 日まで更新されます。選ばない場合は従来どおり 24 時間です。アバターのメニューに「このサーバーからログアウト」があります。
- **管理者アクセスの回復**：**サーバーのマシン上で** `tune-server --reset-admin`（または `--reinitialiser-admin`）を実行してください。表示される使い捨てのコードは 15 分間有効で、そのマシンから「パスワードをお忘れですか？」に入力します。ブラウザーがない場合は `--password-stdin` を付けてください。開いているセッションは閉じられます。インストールガイド（第 9 節）に、システムごとのコマンドが記載されています。
- **`admin` プロファイル**：自動的に作成される管理者プロファイルの名前は `admin` になりました。お客さまが付けた名前は残り、`default` も引き続き使えます。
- **最初の設定で管理者パスワードを作成**：新規インストールでは、ウィザードの中で作成します。
- **認証なしのサーバー**：サーバーのマシンからだけでなく、ローカルネットワークからも管理できるようになりました。**注意**：認証がない場合、ローカルネットワーク上の機器はサーバーを管理できます。ネットワークが信頼できない場合は、認証を有効にしてください。「このマシンからのみ管理する」の設定で、以前のルールに戻せます。

## リモコンアプリ

- 保護されたサーバーでは、まだ更新されていないアプリは、これまでどおり 24 時間ごとにパスワードを求めます。

## お手元でご確認ください

- **プリセット内の「Bypass all」**：Bypass all と DSD の目標の両方を変えるプリセットを「すぐに適用」モードで使うと、トラックを現在の位置から再開します。テストベンチでしか確認していません。再開がきれいかどうか、お知らせください。
