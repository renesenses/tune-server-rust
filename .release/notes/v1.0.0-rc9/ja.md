Tune 1.0.0-rc9、Tune 1.0 の 9 番目のリリース候補です。

## 新機能

- **Tune Circle**：連絡先どうしのプライベートメッセージ。ワンクリックで聴けるミュージックカード、自分のメッセージの削除、通報に対応。メッセージはエンドツーエンド暗号化されておらず、通報後は Mozaiklabs が読むことがあります。
- **Tune Circle**：連絡先リストの「書く」で会話が直接開きます。Enter で送信、スマートフォン向けの表示に対応。
- **Tune Circle**：招待されたサークルを確認し、プレイリストを共有できます。バッジと一覧で通知をまとめ、種類ごとに設定できます。
- **Tune Circle**：ワールド表示で、国別および約 110 km の区域ごとにコミュニティを匿名で表示します。公開マップから自分を外すこともできます。
- **ラジオ**：全体検索で保存した局とディレクトリの局を、複数の語を任意の順で検索できます。局のページにはジャンル、サイト、ストリームが表示され、好みのストリームを選べます。
- **マップとポッドキャスト**：ジャンル、国、ネットワーク別に局を探索でき、リスト表示もあります。複数の国のポッドキャストを閲覧できます。
- **再生の再開**：元のアルバム、プレイリスト、キューに戻ります（シャッフル時も）。ポッドキャストでは数秒巻き戻し、0〜300 秒で調整できます。
- **コレクション**：コレクションとタグでランダム並べ替えと「引き直し」に対応。サービスのお気に入りアルバムを年と音質で並べ替えられます。
- **再生中**：「共有」ボタンで再生中の曲のリンクをコピーします。
- **Oxygen**：プレビューと確認のあと、絞り込み結果全体にタグを付けたり外したりできます。
- **外観**：新しい「Mozaiklabs」テーマ。Mozaiklabs のサインインページがインターフェースの言語とテーマに従います。
- **言語**：ノルウェー語（ブークモール）、ポーランド語、ギリシャ語に対応しました。
- **Android Auto**：お気に入り、プレイリスト、ラジオ、キュー、再生中を表示し、選んだゾーンを操作できます（車内では未検証）。

## 改善

- **車内**：Android Auto でも CarPlay でも、Tune Remote は「この電話」で再生し、自宅のゾーンには触れません。
- **ラジオ**：局が配信するジャケットを表示し、ない場合はロゴを表示します。Tune を再起動せずにディレクトリを更新でき、ストリーム選択は国の制限に従います。
- **TIDAL**：最初の応答が CD 品質のみの場合も、ご契約の範囲で Hi-Res 版を探し続けます。
- **HQPlayer**：曲の切り替えがより確実になり、再起動して再生が始まらない場合は通知します。
- **Devialet**：Qobuz Hi-Res の曲内を移動しても音切れせずに再開します。Devialet AIR では機器で観測された音量を別に表示します。
- **音量**：音量とミュートは各出力の能力に従います。AI アシスタントは音量を少しずつしか上げません。
- **出力**：AirPlay と UPnP/DLNA の両方を備えた機器は両方の形で表示されます。ASIO と CoreAudio はチャンネル割り当て表により忠実に従います。
- **ライブラリ**：機器一覧がコンパクトになりました。フォルダーの絞り込みは最近追加にも適用され、履歴は同じ局の再生をまとめます。
- **リモート再生**：アカウントによるアクセスを QR コードなしで設定でき、アカウントに紐づく機器を削除できます。

## 修正

- **再生**：古い位置報告で移動直後に曲が終わることはなくなりました。ごく短い WAV で連続再生が途切れなくなり、サンプルレート変更が一時的に拒否されても再生が再開します。
- **DLNA とゾーン**：DLNA プレーヤーが告知どおりのマルチチャンネル FLAC を受け取ります。再生中のゾーンの機器を替えると以前の機器が止まり、拒否された転送は元の再生をそのまま残します。
- **TIDAL**：一部の音声リンクによる起動エラーを修正しました。
- **その他**：停止後の CD 取り込み、アラームの順序、新規プレイリストの即時表示、インストール後に消える更新バナー、PostgreSQL での ListenBrainz と Last.fm のキー保存、HTTP キャッシュを含まないバックアップ。
- **セキュリティ**：リモート再生リレーの修正。詳細は別途セキュリティ勧告で公開します。

Spotify は実際の再生確認なしでの提供です。ご自分のアカウントで再生できるか、フォーラムでお知らせください。
