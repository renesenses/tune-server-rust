Tune 1.0.0-rc9，Tune 1.0 的第九个候选版本。

## 新功能

- **Tune Circle**：联系人之间的私信，支持一键收听的音乐卡片、删除自己的消息以及举报。消息未经端到端加密，举报后 Mozaiklabs 可以阅读。
- **Tune Circle**：在联系人列表中点「写信」直接打开对话；按 Enter 发送；界面适配手机。
- **Tune Circle**：可找到受邀加入的圈子并分享播放列表；徽标和列表汇总通知，可按类型设置。
- **Tune Circle**：「世界」视图以匿名方式按国家和约 110 公里的区域展示社区。您可以从公共地图上移除自己。
- **电台**：全局搜索可找到您的电台和目录中的电台，支持任意顺序的多个关键词。电台页面显示流派、网站和音频流，并可选择首选音频流。
- **地图与播客**：按流派、国家和网络探索电台，并提供列表视图；浏览多个国家的播客。
- **继续播放**：可找回原来的专辑、播放列表或队列，随机播放时也一样。播客会回退几秒，可在 0 到 300 秒之间调整。
- **收藏集**：收藏集和标签支持随机排序，并可「重新抽取」；某服务的收藏专辑可按年份和音质排序。
- **正在播放**：「分享」按钮可复制当前曲目的链接。
- **Oxygen**：预览并确认后，可对整个筛选结果添加或移除标签。
- **外观**：新增「Mozaiklabs」主题；Mozaiklabs 登录页跟随界面的语言和主题。
- **语言**：新增挪威语（书面挪威语）、波兰语和希腊语。
- **Android Auto**：收藏、播放列表、电台、播放队列和正在播放，并可控制所选区域（尚未在车内测试）。

## 改进

- **车载**：无论 Android Auto 还是 CarPlay，Tune Remote 都在「本机」播放；家中的区域不受影响。
- **电台**：显示电台发布的封面，缺失时以台标代替；目录无需重启 Tune 即可刷新；音频流选择遵守国家限制。
- **TIDAL**：首次响应只有 CD 音质时会继续寻找 Hi-Res 版本，以您的订阅为限。
- **HQPlayer**：切换曲目更可靠，重新启动未能开始播放时会提示。
- **Devialet**：在 Qobuz Hi-Res 曲目中跳转后继续播放而不断音；Devialet AIR 会单独显示设备上实际的音量。
- **音量**：音量和静音遵循各输出的能力；AI 助手只会小幅调高音量。
- **输出**：同时支持 AirPlay 和 UPnP/DLNA 的设备会以两种形式列出；ASIO 和 CoreAudio 更好地遵循声道映射表。
- **音乐库**：设备列表更紧凑；「文件夹」筛选也适用于最近添加；历史记录会合并同一电台的收听。
- **远程收听**：基于账户的访问无需二维码即可设置，并可移除与账户关联的设备。

## 修复

- **播放**：过时的位置报告不会再在跳转后结束曲目；很短的 WAV 文件不再中断连续播放；采样率切换被暂时拒绝后播放会恢复。
- **DLNA 与区域**：DLNA 播放器可收到所声明的多声道 FLAC；更换正在播放区域的设备会停止原设备；被拒绝的转移不会影响原来的播放。
- **TIDAL**：修复了某些音频链接导致的启动错误。
- **其他**：停止后可抽取 CD、闹钟按顺序播放、新建的播放列表立即显示、安装后更新横幅消失、PostgreSQL 下可保存 ListenBrainz 和 Last.fm 密钥、备份不再包含 HTTP 缓存。
- **安全**：修复了远程收听中继的问题；详情将另行发布安全公告。
