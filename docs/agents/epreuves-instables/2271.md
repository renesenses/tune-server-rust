# Autoplay #2271 : isoler les consignes de fin de piste

Le témoin random_modes crée la première zone de chaque base SQLite isolée.
Mais FINS_SUR_ERREUR, FINS_VOULUES et DERNIERS_LOTS sont des états du processus,
indexés par zone, sans distinguer les bases. Le banc fichier_abime_8483 crée
également sa première zone et passe par le code qui pose une fin sur erreur.
Une fin étrangère consommée par handle_track_end interdit la continuation.

Ce seul test tourne dans un processus neuf. Les huit scénarios (quatre modes,
avec et sans piste de streaming précédente), les files, les événements et la
sortie MockOutput sont conservés. Aucun périphérique audio réel n’est utilisé.
Le parent exige un test réussi, aucun ignoré ; le cas vide/off reste inchangé.

Contre-épreuve : supprimer uniquement la continuation des modes aléatoires
dans prolonger_la_file. L’assertion de taille de file doit rougir pour RandomAlbum.
Restaurer par copie, puis vingt passages consécutifs sous charge.
