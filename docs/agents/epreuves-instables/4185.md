# Passage DR #4185 : isoler les pauses et les rangs

Le témoin de lancement, refus du doublon et fin de passage attend une jauge
`playback`, puis une passe terminée. La pause utilisateur globale précède la
garde de lecture dans `Passe::courir` ; un autre module qui suspend les tâches
peut donc remplacer cette attente par `paused` ou retarder la fin du passage.
Les rangs d’analyse sont eux aussi partagés par le processus.

Ce seul témoin s’exécute dans un processus neuf. Le parent exige exactement
un test réussi, aucun ignoré. Les assertions 202/409, jauge, registre, fin et
retrait des candidats restent conservées ; aucun abandon anticipé n’est ajouté.
La contre-épreuve remplace seulement `waiting_reason` par `null` dans la
réponse de production : la jauge doit toujours faire rougir le témoin.
Restaurer par copie, puis vingt passages consécutifs sous charge.
