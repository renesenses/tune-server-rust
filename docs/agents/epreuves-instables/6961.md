# Réserver le port de l’ancienne adresse dans le test unicast de #6961

Le job PostgreSQL 137095519878 de la PR #9318 a compté 4 031 tests réussis et un échec sur le refus d’un autre UDN. Le banc choisissait un port TCP puis le libérait avant d’ouvrir le serveur HTTP. Si un serveur reprenait ce port, la première sonde HTTP pouvait trouver une description avant même le recours à UDP. Le journal CI donne le verdict du test sans préciser le port choisi.

Le test garde désormais l’ancien port ouvert jusqu’à la fin de la recherche. Le listener accepte puis ferme chaque connexion. La sonde HTTP doit donc passer au recours unicast. Le répondeur incrémente son compteur dès la réception du M-SEARCH, avant l’envoi UDP qui peut réveiller la sonde. Le test attend ensuite la fin du répondeur pour vérifier que l’envoi a réussi avant de contrôler le refus de l’autre UDN.

Pour reproduire la contre-épreuve, neutraliser la comparaison d’UDN dans `redecouverte::rechercher_location_par_unicast`. Le test doit échouer sur l’assertion « un répondeur d’un autre UDN ne doit pas être pris pour l’appareil mémorisé ». Restaurer la comparaison puis exécuter le même test vingt fois sous charge. Le banc utilise la boucle locale et des ports éphémères.

```sh
cargo test -p tune-server --lib le_recours_unicast_ignore_un_autre_appareil -- --nocapture --test-threads=1
```
