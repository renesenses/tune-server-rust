# Déplacer la racine #8676 : isoler le droit de scanner

La suite #8917 a observé « scan_running » (409) au lieu de « none_found » (422)
dans remplacer_le_chemin_par_les_routes_8676. La base et les fichiers sont
propres au test, mais ScanGate est global. Le mutex de certains bancs ne
couvre pas la durée des scans de fond lancés ailleurs.

Ce seul témoin tourne dans un processus neuf. Le parent exige un test réussi,
aucun ignoré. Les contrôles de prévisualisation, refus, confirmation périmée,
chemins, identifiants conservés et réglages restent inchangés. Le mutex et
l’attente initiale existants sont conservés dans l’enfant.

Contre-épreuve : retirer seulement le contrôle confirm_tracks dans la route
d’application. Le test doit refuser le succès sur une confirmation périmée.
Restaurer par copie, puis vingt passages consécutifs sous charge.
